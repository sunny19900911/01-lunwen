# 别人是否已经证明过：目前能够确认的边界

**现在不能确认核心具体结果具备发表新颖性。** 有些方法和现象已经有明确先例；有些具体结论完成了本团队的数学检查，但同条件发表覆盖仍未知。二者必须分开。

| 当前内容 | 已有证据支持什么 | 目前的判断 |
|---|---|---|
| Maxwell串联储能、端口功与真实耗散分账 | 标准被动储能记账；本轮核对的是模型/单位/符号及端点条件 | 经典内容，不认作新耗能规律 |
| 完整装置力到固定位置的模态/Green卷积、耗散预算接Hölder位移界、输入能量粗界 | 已核经典工具及本模型映射；MIT讲义支持Hölder端点，不是Maxwell专门定理 | 条件应用与接口，不认作新理论；实际算子和数据仍需认证 |
| 加装非线性Maxwell后，某些位移/漂移相关指标反升 | Correia2024可读原文已报告这一广义现象；本项目严格模型/峰定义/初态等不能自动与其等同 | 广义现象已有先例，不能宣称首次发现；严格基准的具体发表覆盖未知 |
| 整体能量及装置历史相同，固定位置峰仍不同的明确合成基准 | 本轮对称交换、连续误差及尾段证据已审；工具经典 | 可作有范围的基准/信息边界说明，但具体同条件发表未核清，严谨证书不自动等于创新 |
| 非零末力、末总变形自由、给定峰的完整真实耗散区间，以及固定耗散反推峰集合 | 本团队已审解析结论；Liberzon的HJB全局充分性等是经典背景，未完成其到本题全部公式的严格发表特例判定 | 具体发表覆盖未知；不能从未命中、邻近条件不同或原文失败推出首创 |
| 连续速度下原耗散两端只作上下确界的补充 | 在0<α≤1等明确条件下，本团队已独审比较/等号/平滑校准；未做完整同条件发表排重 | 经典正则性边界说明，不额外认原创，也不扩为建筑可实现性 |

最近的跨领域原文是Goetz2013的磁刺激脉冲优化。原文确有真实Joule成本，但所核限幅只针对电感压LI′，不含电阻压降RI；还有所核参数化的末流与神经约束差异。因此尚未建立它对当前“总端压受限、指定非零末流、恰峰、完整成本集合”的覆盖。这个判断只限已核部分，不能排除整篇其他变体或整个领域。

Gusev2017目前只有书目层记录，正文未得。另一个高校公开PDF线索本轮一次访问403，连题名/作者/版本和模型都未核到，不能将它判为相关或不相关。检索未选到合适候选、访问失败、读到正文但条件不同，是三种不同的结果。

因此，当前安全的论文表述是“给出有条件的解析结果、基准与接口，并说明适用范围”。不应写“首次”“现有文献均未证明”或“已经建立真实结构最优布置”。核心结果能否承担正式论文的主要创新，还需要可读的同条件原文对照，或对最接近的一般定理作完整、可核查的特例判定。

# 主控直接复查Londoño2014的输出口径

本轮主控通过公开机构原文直接读取PDF文字及Table IV/V所在页（零起算PDF页13，印页2011），与角色6 R013报告核对。没有把根文字读取记为独立求解或当前合成例的证明。

来源：[Londoño、Wagg、Neild，2014机构全文](https://eprints.whiterose.ac.uk/id/eprint/81371/1/WRRO_81371.pdf)，DOI10.1002/eqe.2433。

Table IV把J1定义为各层相对于无控同层加速度峰的比值再取最大；J3是固定顶层位移峰的比值。Table V在同一有限地震记录中，第一组Northridge给J1=1.54而J3=0.28；Imperial Valley相应为1.15和0.60。因此加速度可增大同时顶层位移下降，不能把“响应增大”直接转录成“固定u1位移增大”。按原文所示max公式解释，不把提取文本中的范数标签解释成时间积分。

这是α=1及有限记录的已有数值例；原文未给本轮α=3/10固定坐标截断正弦的误差或无限尾证书。它明确阻止把一般局部反升现象称为新发现，但不能用不同输出替代当前更窄命题的同条件先例。当前具体证书的发表覆盖仍未闭合。

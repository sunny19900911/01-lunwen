# 固定频率下各阶单位参与响应的阻尼变化

**36阶×3波共108行均已复核。单位核峰幅比A8/A5为0.70894—0.93645，此次范围内无反升；相同的ζ=5%→8%并不产生各阶相同的峰幅比。** 此结论针对同一固定频率、同一输入下的单位参与运动，不是楼层剪力贡献。

恢复方法：只用R002已冻结的N36 elastic逐阶项与固定raw coefficient，每阶选择Story5/12中绝对系数较大者，取`g=term/coef`；同时从另一层独立恢复并核对。本缓存的`g_r=ω_r²q_r^(Γ=1)`，其中单位参与相对位移满足`q¨+2ζωq˙+ω²q=−ag`，零初始条件。g的单位为m/s²；同一阶固定ω²乘法不影响下列比值。未重新求解ODE或拟合。

定义`Aζ=max|gζ(t)|`、`ρ=A8/A5`和`ε=||g8/A8−g5/A5||₂/||g5/A5||₂`。峰时刻由原输出网格首次绝对峰确定，波形差在相同网格直接计算，不对齐峰时刻、不插值，ε不等同纯相位差。前3阶结果如下，每格为“ρ / ε”：

**不依赖常数输出乘子：** 对两种ζ共同的任意非零常数c，令`g̃ζ=c·gζ`，则`Ãζ=|c|Aζ`，故ρ不变；归一波形同时乘`sign(c)`，故ε也不变。因此同一阶实际参与因子Γ的乘法，以及固定模态归一化的常数变换，均不改变这些指标。**Γ=0时实际该模态不受激，实际峰幅比为0/0而无定义；本表仍是Γ=1单位核，不能据此宣称该模态有实际贡献。** A5/A8本身是明确约定下的单位核幅值，不能冒充任意归一化下不变的实际模态幅值。

验证：两层共216项核一致性检查，最大绝对误差2.22×10⁻¹⁶ m/s²、相对L∞误差2.53×10⁻¹⁶；直接由两层逐阶项计算的ρ、ε与恢复核结果吻合，另用负常数−3.7复核归一化不变性，最大差2.22×10⁻¹⁶。来源SHA与冻结清单一致，未输出完整核时程。**这些结果支持增ζ改变各阶幅值和波形，但不据此认定某阶主导某层剪力，也不赋予高阶拟合系数物理含义。**

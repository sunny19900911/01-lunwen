# 原生楼层剪力峰值的同刻降幅与重选修正

**36对记录均满足精确记账式；20对发生控制峰时刻转移，另16对保持原峰时刻且修正项为零。** 数据限定为固定M、K和输入下经典模态阻尼比5%与8%的原生Bottom截面X向楼层剪力，包含Story1—12及SHW3X、SHW4X、RH4X，力单位kN。

取原生输出网格上的`P5=max|V5(t)|`、`P8=max|V8(t)|`，令`t0`为5%绝对峰时刻，`s0=sign[V5(t0)]`，定义：

\[
D=s_0[V_5(t_0)-V_8(t_0)],\qquad M=P_8-s_0V_8(t_0)\ge0,
\]
\[
P_5-P_8=D-M,\qquad r=\frac{D}{P_5}-\frac{M}{P_5}.
\]

`D`是在同一时刻、沿原控制峰符号方向的剪力减小量；`M`是8%全时程重新选取绝对峰后，相对原锚点有符号值的非负修正。二者给出工程上可复核的峰值记账：检查原控制时刻的减小量，还须扣除重新选择控制峰造成的修正，才能得到实际峰值降幅。这里的百分数均以同一个P5归一化，不是分力份额或因果相位份额。

按`M/P5`由大到小，最明显一例是**RH4X / Story1**：原控制峰为21.68s的正峰，新控制峰为12.20s的负峰；`P5=10566.7533`、`P8=8528.6654`、`V8(t0)=8140.3611 kN`。因此`D=2426.3922 kN`，`M=388.3044 kN`，净峰值减小`2038.0879 kN`，对应`22.9625%−3.6748%=19.2877%`。这说明仅查看原峰时刻会高估全时程峰值降幅。

来源与核验：先核对R003冻结缓存864个键、72条原生向量与两种阻尼状态的时间轴，且N24/N36命名空间中的原生曲线逐点相同；计算只读取`native`及`t`。36行峰值、峰时刻与交叉值均与R003原生配对表吻合；双精度记账闭合误差为0 kN。网格步长0.02s，绝对峰并列时保留首次出现，未插值、拟合、加阶或输出完整时程。**本方法核算峰值变化，并不单独识别波形变化或相位变化的因果贡献。** 完整36行及符号、无转移标记、源行号见`native-peak-accounting-all12-36.csv`；来源SHA及独立标量复核见`verification.json`。

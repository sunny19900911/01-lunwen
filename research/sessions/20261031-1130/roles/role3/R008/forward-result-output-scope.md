# 新前向结果的输出定义与作者用语

角色③仅针对新冻结的④R004前向结果整理出处和表述，不重复审旧稿，也不重算数组。本项数值转述来自生产报告；后续有符号对照及独立数值审核由主控接入。

## 1. 位移与剪力误差采用不同定义

④R004保留位移符号，比较u_ref与u_native，216条CM对照最大NRMSE为0.35437%。剪力的当前定义则为

$$\varepsilon_{\mathrm{abs}}=
\frac{\|\,|V_{\mathrm{ref}}|-|V_{\mathrm{native}}|\,\|_2}
{\|V_{\mathrm{native}}\|_2}.$$

因此0.65822%是72条弹性惯性投影参照中最大的绝对值曲线NRMSE，不是已确认作用侧后的有符号剪力NRMSE。绝对峰误差最大为0.23517%。绝对值会丢失符号；即使整条曲线反号，绝对值曲线也相同。表头和正文应保留“绝对值曲线”或“幅值对照”，不能只写“剪力时程误差0.658%”。

经典阻尼平衡项参照全部保留。其误差较大说明两种参照与数据的数值吻合程度不同，但不能单凭误差排序认定软件VX的物理组成。

## 2. 现有CSI原文对符号支持到哪里

CSI Analysis Reference Manual，2016 Rev.15，印刷48/PDF70：

- 支座反力是作用在关节点上的力，按关节点局部轴报告。
- Element Joint Forces表示其余结构对单元的作用，给出f=Ku−r，并要求与单元内部截面力区分。

同手册印刷143–144/PDF165–166：框架内部截面力按正、负截面及单元局部轴定义；相对两面同一内力的全局作用方向相反。PDF70与166已渲染并查看。

这些内容支持“关节点力、单元内力与切口作用侧需要分别定义”。它们没有在本次已核页中直接给出ETABS Story Forces表Bottom VX相对本文a_sᵀKu的映射，所以不能据这些一般定义直接认证η=−1，也不能把对侧可反号当作该表已有明确出处。当前仍需具体软件切面定义或独立自由体检查。没有新增第三份补充文献或额外网页。

原生参与因子中的惯性荷载负号，与软件切口力的作用侧符号，是两件不同的转换；前者不能用来确定Bottom VX的η。

## 3. 对U/P/C的影响

对一个物理切口，若只有作用侧使整条参照曲线共同乘固定η=±1，则各阶绝对峰幅总和U、合成绝对峰P及C=P/U均不改变。参照模型自己的U/P/C可以按其已声明的恢复力正向计算；与软件同刻有符号剪力项对应时，仍需先确认η。该事实不允许逐记录、逐模态或逐时刻选择正负号来降低误差。

符号不确定也不能替代另外两个条件：Ritz目标切口恢复关系，以及参照坐标与实际FNA坐标的区别。这两项即使在确认η后仍应保留。

## 4. 前向坐标与观测反演的区别

在线性解耦参照模型内，频率、阻尼、输入和初值均已给定时，s_r由方程确定，q_ref,r=Γ_rs_r也随之确定。216条CM吻合是这一固定前向链在现有观测量和输入下的数值支持。

②R004另审的是：不追加动力学约束，只给36个瞬时质心平动量，能否唯一反演300个实际坐标。该问题的秩和零空间条件与前向求解不同。不能把位移预测误差直接写成实际每个q_r的误差；同样，瞬时反演不唯一也不否定已声明线性参照模型内的前向解唯一。

## 5. 可供新稿使用的段落

“采用同一组固定质量、振型和频率，分别计算5%及8%阻尼下的单位输入响应，再前向合成全部质心位移。216条有符号位移对照的最大NRMSE为0.35437%，表明该线性参照在现有输入和质心观测下具有较好的预测一致性。剪力现阶段先比较逐时绝对值和绝对峰，弹性惯性投影参照的最大绝对值曲线NRMSE为0.65822%，最大绝对峰误差为0.23517%；其与软件Bottom VX的作用侧映射另行核对。上述结果不以总剪力回归确定系数，所用q_ref属于已定义的线性参照，不等同于已取得实际FNA原生模态坐标。”

这段数值以④R004冻结生产结果为准，纳入最终稿前接入主控所收独审结论。当前不使用“真实逐阶分担已闭合”或“已验证Ritz残差为零”等表述。

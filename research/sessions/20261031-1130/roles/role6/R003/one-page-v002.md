# R003：现有CM观测能否唯一恢复单阶响应

**单阶可恢复与观测覆盖率高是两个问题。** 以下针对同刻带符号观测y=u_obs=Aq、任意q∈R^n；A使用同一模态基、单位及完整列，不能先删掉未观测模态。18CM的XY共36行、300阶，rank(A)≤36排除全300坐标同时唯一，但不单凭行数排除某一特定q_r。

## 1. 单阶唯一性的充要条件

对所有与y相容的q，q_r均相同，当且仅当

e_r∈row(A) ⇔ 存在l_r使Aᵀl_r=e_r ⇔ 对所有h∈ker(A)，e_rᵀh=0。

成立时q_r=l_rᵀy。必要性：若e_r不在行空间，令P=A⁺A、h=(I−P)e_r，则Ah=0且e_rᵀh=||h||²>0；q与q+αh给出同一观测，q_r却可随α任意改变。充分性由l_rᵀAq=e_rᵀq直接得到。这是线性代数判据，不依赖质量参与率。

可操作量是d_r=||(I−A⁺A)e_r||₂，数学上d_r=0才满足上述条件。浮点“接近0”须同时报告秩、已有SVD截断与源精度，不自行新增阈值认证精确唯一；最小范数A⁺y只是选出一个解。可逆行加权不改变行空间；若模态列缩放改变了q定义，选择向量也须相应换算。即使唯一，恢复系数||l_r||大仍会放大观测误差。

## 2. η≈.99为何不自动唯一

若η表示所测自由度包含的该模态质量范数比例，它只描述该列的覆盖，不检验其他299列能否混入。解析例取M=I，完整Φ为首行(√.99,√.01)的正交旋转矩阵，仅观测第一自由度，则A=(√.99,√.01)、η₁=.99，但h=(−√.01,√.99)满足Ah=0且h₁≠0，故q₁不唯一；这里未做矩阵数值实验。若η特指行投影对角e_rᵀPe_r，则d_r²=1−η，.99同样不是精确唯一。两种η须分别命名。

## 3. 遗漏自由度的条件误差界

假定模态质量正交，m_r=φ_rᵀMφ_r>0，真实坐标满足q_r=φ_rᵀMu/m_r。把自由度分为观测O和遗漏H，且M在该划分下正交；等价地使用M正交投影P_O、P_H。定义η_r=||φ_r,O||_M²/m_r及完整模态质量归一的估计qhat_r=φ_r,OᵀM_Ou_O/m_r，则

q_r−qhat_r=φ_r,HᵀM_Hu_H/m_r，

|q_r−qhat_r| ≤ √(1−η_r)/√m_r · ||u_H||_M ≤ √(1−η_r)/√m_r · ||u||_M。

η=.99仅给出系数.1/√m_r，仍要乘未知的遗漏响应范数；不能写成“误差1%”或固定绝对误差。相对误差还需除|q_r|，接近零时可很大。若改除观测模态质量m_r,O=ηm_r，估计变为qtilde=qhat/η，且qtilde_r−q_r=[(1−η)q_r−(q_r−qhat_r)]/η，不能沿用同一误差界。CM集中质量近似或平转质量耦合未核时，上式也只保留为条件，不将36个平动观测直接冒充完整M范数。

## 4. 本轮执行与裁决

①核同一工况、相同网格的CM带符号时程及A的模态坐标定义；②由④报告e₂/e₁₀/e₁₃的行空间距离和既定秩诊断，不重复矩阵实验；③满足条件者给出恢复向量，其他只报告可恢复的观测组合；④误差须绑定实际观测误差、遗漏响应范数或有依据的先验，未知就保留条件式。

上述是不加动力约束的瞬时判据。利用已知方程、初值、输入的时间观测是另一个问题，不能凭行数否定它，也不能用未核的解耦SDOF替代实际FNA坐标。即使q_r恢复成功，真实逐阶弹性剪力仍需另核Ritz切口恢复关系；质量投影B和单位输入坐标Γs_r不能自动替代它。

# 基准响应预测候选阻尼：工程判据与公平比较

结论：用预测区间相对项目改善目标的位置决定哪些楼层改善不足、哪些达到目标、哪些需要完整复算。区间覆盖率、漏判和复算比例共同评价；本项冻结规则，不提供工程预测数组或速度结论。

## 工程量与决策

同一输入、方向、楼层及计算时间窗，P5=max|V5(t)|，Pζ=max|Vζ(t)|，D=1−Pζ/P5。Dreq由项目输入；本轮演示Dreq=0.10，表示峰值降低至少10%，不是规范阈值。D<0表示峰值增大。以下要求P5>0。

若候选峰值有效区间为[LP,UP]，则改善区间为[LD,UD]=[1−UP/P5,1−LP/P5]，方向不可颠倒。物理峰值非负；负的下界可截为0，区间无效、非有限或基准峰值为0时转复算，或采用预先给定的绝对剪力容差，不计算失效的比值。

| 条件 | 工程判断 | 后续动作 |
|---|---|---|
| LD≥Dreq | 达到目标 | 依区间所对应的可靠性使用 |
| UD<Dreq | 改善不足 | 调整候选阻尼或按设计需要复核 |
| LD<Dreq≤UD | 需要复算 | 完整分析后判断 |
| UD<0 | 确定不利，属于改善不足 | 单独列出峰值增大 |
| LD<0≤UD | 可能不利 | 保留不利风险标记，不随主分类隐藏 |

目标等号归“达到”；UD=Dreq且LD<Dreq仍需复算。解析上界、统计预测区间和未加区间的点预测分别标明：经验覆盖不能改称确定保证；仅有点预测时，给出暂定类别，不纳入有区间支持的可靠判定数量。区间必须覆盖同一离散输出网格的整个计算时程峰值；若声称连续时间峰值，还需计入采样误差。P5有误差时须同时传播基准误差，本表默认其为固定参考值。

## 如何判断预测有用

逐输入—方向—楼层—候选阻尼记录真值、点预测、区间和三类决定，保留全部失败案例。报告：
1. 峰值误差及D误差，均值之外列最大值、各输入最差值；D用百分点，避免低改善值附近的相对误差失真。
2. 区间覆盖率和宽度(UP−LP)/P5；同时报告需复算比例、两种确定判断各占比。覆盖全部但全部需复算的区间不构成有效筛选。若项目有最大允许宽度，必须在看目标真值前给定；宽但完全位于目标一侧的有效区间仍可作该侧判断。
3. 改善不足漏判：真D<Dreq却判达到的数量/全部真改善不足数量；另报这类数量/全部判达到数量。把需复算另列，不能剔除后只报低漏判。不利漏判：真D<0却未被改善不足或复算接住；另列未标记可能不利的数量。分母为0时报不适用，不报0%。
4. 若同一方案要全部楼层达到目标，采用“全部楼层均判达到”规则；单层经验覆盖率不能直接当全楼联合可靠性。同一事件的方向和楼层不是独立事件，不把大量相关行数当有效独立样本数。

## 三个公平基线与完整参考

| 基线 | 固定实现与信息限制 |
|---|---|
| 整体统一折减 | P预测=a(ζ)P5；同一ζ所有楼层用同一系数。系数由事先规则或训练组确定，不用测试组目标峰反推。 |
| 固定少阶预测 | 只由5%资料选定阶数、振型集合和求和方法，随后求候选下该集合的完整时间窗峰值。遗漏阶次误差不能从目标真值补回。 |
| 只在旧峰时刻计算灵敏度 | 冻结5%最大绝对值时刻及并列峰处理规则，仅在该时刻外推；不得再用候选真峰时刻修正。 |

待评方法则用基准灵敏度外推整个时间窗并重新寻峰。四种方法使用同样的5%输入、结构参数、时间步、时间窗和候选阻尼；完整候选求解仅产生参考真值。比较点预测时统一指标；比较区间筛选时给予相同校准资料与评价规则，不把没有区间的基线当有保证的筛选。

## 冻结、成本与设计步骤

先冻结算法、系数、阶次、区间构造及候选取值，再生成新目标参考响应。旧8%结果已看过，只称既有案例复核；新候选按预定次序保留全部结果。训练/校准/评价按独立模型或事件划分，不随机拆时刻；同一事件X/Y合组，任何目标真值不进入选模、残差估计或阈值调整。若残差需要完整候选解才能得到，该步骤只能作后验诊断，不能计作提前预测输入。

工作量包含基准计算、灵敏度及高阶灵敏度、残差/区间、振型求和、寻峰、数据处理，以及触发的完整复算。分别记录一次准备和每个候选的增量，统一缓存/硬件条件；按整个工况实际复算次数计费，不把同一次全模型求解重复按楼层收费，也不能只统计预测内核而漏掉复算。实际计时和相同误差要求成立前不主张提速。

设计时依次：确定项目Dreq和候选阻尼；计算5%基准及所需灵敏度；预测各层峰值与区间；列出改善不足、达到与需复算楼层及不利风险；对需复算工况完整分析并核对设计目标。

可争取的唯一贡献：在明确的线性模型和阻尼变化范围内，将基准响应外推与峰值误差区间结合，用可复核的漏判和复算代价识别增阻尼后改善不足的楼层。成立程度等待理论审核和工程验证；Taylor展开、灵敏度方程及区间换算本身采用经典方法。

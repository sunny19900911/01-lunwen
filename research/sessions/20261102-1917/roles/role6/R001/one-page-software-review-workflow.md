# 拿到常规软件输出后如何复核楼层剪力

把“改善最小的记录”和“绝对需求最大的记录”并列保存，分别回答改善多少、仍有多大剪力；两行可以由不同输入控制。它们用于找到应查看的楼层、输入和时段，不直接排结构危险程度。

1. **先把比较对象配成对。** 获取两模型Story Forces中相同楼层、方向和Bottom位置的完整有符号剪力时程，记录模型名、输入工况、单位、时间步和观察窗。核对输入样本与缩放，以及质量、刚度和阻尼设置的已知差别；输入或输出口径不能配对的记录单列，主体参数等缺项明确注明，不据此归因于阻尼变化。X/Y方向保留各自工况身份，不把方向记录数当独立地震数。
2. **每条输入分别取两模型自身峰。** 对同层、同方向和同一输入，取P_B=max|V_B(t)|、P_M=max|V_M(t)|，同时保留各自峰时t_B、t_M。并列峰记录其时刻或沿用已说明的取值规则，不把参考模型在t_B的读数当作P_M。
3. **同一条记录内算减幅与原峰时偏差。** 记A=|V_M(t_B)|，r_peak=100(1−P_M/P_B)、r_at=100(1−A/P_B)，d=r_at−r_peak=100(P_M−A)/P_B。r以%列示，d以百分点列示；峰时差另记Δt=t_M−t_B，单位s。P_B=0时保留绝对峰，归一减幅标为不适用。
4. **每层每方向保留两类控制输入。** e_r取同一输入集合内r_peak最小的工况；建议本轮将e_Q定义为参考模型P_M最大的工况，并在表头写明所复核的模型。若工程需求对象改为其他模型，应重新明确需求列名及控制输入。每行的P_B、P_M、峰时和d全部取自该行输入，不跨输入拼数；并列控制保留工况身份。
5. **按下表读两行，再查看完整明细。** 最小减幅行看改善及原峰时高估量；最大需求行看所选模型的绝对剪力。两行均回看t_B、t_M附近曲线、相邻楼层及同层其他输入。最小—中位—最大减幅可作背景，但不替代最大需求行。若e_r=e_Q，同一源记录可标两种用途，不能计作两个独立样本。
6. **把响应复核接回原设计验算。** 对所选模型的需求另查既有承载力、层间位移角和组合要求；含装置模型只在已有覆盖内核对连接方向、层剪峰时的有符号合力及装置自身峰。Bottom输出含义未核清时按软件楼层剪力使用，不直接扣装置力。

|---|---|---|---|---|---|---|---|---|
|第s层/X或Y|最小减幅控制|e_r|P_B(e_r)；t_B(e_r)|P_M(e_r)；t_M(e_r)|本输入减幅|本输入原峰时高估量|本输入峰时差|两模型峰附近时程|
|同层同方向|参考模型最大需求控制|e_Q|P_B(e_Q)；t_B(e_Q)|P_M(e_Q)；t_M(e_Q)|本输入减幅|本输入原峰时高估量|本输入峰时差|绝对剪力及既有设计验算|

后台明细另保留A、r_at、输出位置、源记录编号及时间网格。若还需展示全样本最大d，应独立列出该条记录，不将它挪到最小减幅行或最大需求行。

读表时应能逐句回答：“哪条输入使这层改善最小？”“哪条输入使受评模型剪力最大？”“两模型各自峰在哪里？”“只读原峰时会高估多少？”减幅小不等于需求大，需求大也不等于承载力最不利。

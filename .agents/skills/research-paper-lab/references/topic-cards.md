# 选题卡与演变记录

选题卡把不断变化的研究判断压缩成用户可以比较和决策的依据。主控可以推荐继续、收窄、转向或暂缓，但最终选题决定由用户作出；团队意见不记作用户批准。

## 记录范围与所有权

每个候选选题分配稳定的 T-ID。主控负责当前选题卡、历史快照和决策记录；可以委派整理者写提案文件，再由主控整合，避免两个角色同时更新卡片。

课题中按需采用：

```text
research/topic-cards/T001.md                    # 当前卡片
research/topic-cards/history/T001/v001.md       # 决策快照，不覆盖旧版
research/topic-cards/events.md                 # 演变事件，追加记录
research/topic-cards/decisions.md              # 用户实际决定与仍待决问题
```

新研究使用 [选题卡模板](../assets/topic-card.template.md)。已有选题卡先保留其格式，补充证据引用、演变事件和待决项，不强制迁移。

## 时间与事件触发

- 每次研究检查点核对选题卡，默认与十分钟汇总同步。
- 文献复查改变创新性判断、新反例推翻关键命题、证明成立或失败、数据/拟合验证状态变化、成本边界变化时，及时记录事件并更新当前卡。
- 默认每30分钟形成一次决策快照，可由用户改为轮次或其他间隔。实际运行不足该间隔时，在本轮结束形成首版；不会为了凑时间等待。
- 没有实质变化时记录“已复核，无新增变化”，无需复制一整张相同快照。用户明确要求固定周期报告时按其要求交付，并清楚注明无变化。
- 重大转向、关键反例或需要用户决定时，立即形成决策版，不等下个周期。

这些规则只在实际活跃研究或已设置的调度中执行。未创建定时任务时不承诺离线周期更新；用户仅要求增加技能功能时，完成设计和模板即可。

## 卡片必须保留的决策维度

1. **问题与价值**：对象、一句话问题、工程/学术价值和成功/失败判据。
2. **文献位置**：最接近的已读论文、原文定位、相同点、不同点、全文获取状态。创新性仍待核查时明确写出，不能把检索未命中当作无人研究。
3. **候选贡献**：理论、方法、现象、数据或工程边界分别依靠什么证据，最强主张是哪条 C-ID。
4. **证明与反例**：正在验证的命题、证明缺口、有效反例、数值支持范围与被放弃的旧版本。
5. **数据与拟合**：可用数据、缺口、公平对照、独立验证、可识别性、实际误差和外推限制。
6. **可执行性**：已用与预计资源、求解/导出依赖、授权边界、下一项最低成本检验。估算与已发生事实分开。
7. **成稿条件**：已有章节/关键图表、完成核心论证还缺什么，目标期刊要求是否已核查。
8. **选择与风险**：继续、收窄、转向、暂缓各自得到什么、需要什么以及尚不确定什么。

只填有依据的判断；没有依据就标为未知并给获取方法。无需用虚构分数、伪精确录用概率或团队投票制造排名。多个候选可用一张对照表，比较相同维度。

## 演变事件

每个事件至少记录真实时间、T-ID/版本、发生变化的字段、旧判断、新判断、触发的 C-ID/E-ID/L-ID、影响和下一步。历史不能只记录最后结论，也要保留为什么改变方向。

回溯整理以往材料时，区分事件实际发生时间与本次整理时间；未知的历史时间标为未知，并注明这是回溯重建。不能把今天生成的v1快照伪装成当时已存在的卡片。

例如以下只是记录格式，不代表真实研究结果：

```text
事件：T001 v1 → v2
变化：从“普遍单调性”转为“非单调边界”。
触发：反例E004经验证，满足C001 v1全部假设。
旧主张：所有输入下响应随参数不增。
新候选：识别出现非单调响应的条件与评价指标差异。
文献影响：L003是否已覆盖同一条件，仍待全文复查。
论文影响：引言贡献和结论暂不采用新候选，先做独立检验。
下一步：验证者复核边界，文献角色核对L003原文。
决策状态：待用户决定是否按新方向继续。
```

新数据或文献使原结论失效时，回填当前卡的待核验标记并追加撤回事件；历史快照保留原时间和当时证据，不改写成团队早已知道。

## 交给用户的决策版

控制在一屏可读摘要并附完整卡片路径，依次说明：

- 当前最值得研究的题目与一句话问题。
- 自上一版起最关键的变化及其证据。
- 当前能站住的贡献、最强反对证据和最大的缺口。
- 两到三个实际可选路径：收益、下一步和资源，推荐项要有依据。
- 明确需要用户决定的事项、决定后会执行什么。

用户尚未决定时可继续不依赖该决定的文献复查、证据整理和有限验证，不以“等待定题”为由停掉所有工作，也不擅自改变已批准的研究主线。决定到达后记录用户选择、时间和范围，更新任务；不要把预选项或沉默当作同意。

向用户展示卡片是研究交付，不意味着已发送邮件或其他外部消息。向其他聊天或应用发送仍须遵循相应的明确授权。

## 定时任务中的选题卡动作

若已获授权设置持续研究，在主控自动化提示词中加入：

> 每次检查点核对选题卡；把文献、猜想、证明/反例和数据拟合引起的实质变化追加到演变记录。按研究计划的选题卡间隔形成决策快照，默认30分钟；重大变化或需要用户选择时立即形成。给用户呈现变化、证据、可选路线和建议，最终决定由用户作出。未变化时遵循用户的通知偏好。恢复时从最后快照和事件继续，防止重复生成；已有明确批准的主线不能因内部讨论自动替换。

卡片间隔与十分钟检查点共用同一主控调度，不额外启动互不协调的计时任务。

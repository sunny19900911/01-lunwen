# Maxwell能量、局部输出与模态尾项：最小可核接口

maxwell-modal-interface-v001；2026年10月18日。阶段研究接口文档，非投稿定稿或最终选题。仅整合已准入R018/R019/R020及角色3来源说明；不报告当前建筑的已认证常数，不声称新方法或首创。工程v006、单器件理论附录及旧稿不改。

## 1 用户可以怎样用：先定一个位置和一只器件

先选一个固定目标，例如指定节点某方向的相对位移，或两固定点的位移差；再选一只Link，固定其I/J实际端点、局部轴、偏置和运动学映射。前者写成y=ℓᵀu，后者的总伸长写成δj=Bju。逐时切换控制Label的最大Drift记录不是固定ℓ，Angle=0也不给出实际全局轴。

最小导出可以只含该目标及该器件相关的保留模态分量，不默认索要全楼节点时程。每个模态一行，保留同一Modal Case、同一缩放与共同相位：

| 小表字段 | 含义与需要保留的身份 |
|---|---|
| 模态号、Eigen/最终Ritz标识、ωr | 同一质量源和刚度状态；ω用rad/s，Hz需乘2π |
| 目标点原始有符号形状与Lr | Lr=ℓᵀφr；固定两点差需两点形状及真实权重 |
| 器件I/J端有符号形状与Hjr | Hjr=Bjφr；含实际轴、刚臂/偏置和必要转角分量 |
| 输入列原值、定义与Gr | Gr=φrᵀb；对应同一输入方向、缩放和惯性符号 |
| 广义质量mr或已质量归一的证明 | 必须与所给原形状同缩放；列名不能代替字段公式 |
| 实际背景dr及其定义 | 共同模态基下dr=2ζrωr须已核；设计阻尼百分比不等于实际C |

表外还要有：实际输入力模式b与共同输入ag(t)的范数/单位/窗口，完整初态能E0，所用M/K/C的物理与约束身份；若只保留有限模态，再补下文的总量上界和全尾下界。ηj须由完整质量信息或独立认证上界获得，不能拿少数Hjr平方和直接充完整值。

只有频率和“阻尼%”不够：它们没有给目标点、输入及器件端口的空间投影，也没有给输入强度/初始储能、遗漏模态或实际背景阻尼的身份。高全局参与率主要关乎指定输入，不能单独控制这个局部目标或器件端口的尾投影。以下系数虽有些只使用平方，仍保留L/G/H原符号，便于审核共同缩放和相位；参与率平方量不能反推出符号。

## 2 完整能量到固定位置位移

使用同一约束后有限维坐标，常矩阵M=Mᵀ≻0、K=Kᵀ≻0、C=Cᵀ⪰0。质量忽略的Maxwell支路满足固定kj,cj,αj>0，固定功共轭端口Bj/Bjᵀ，主体与器件方程为

$$\dot u=v,\qquad M\dot v+Cv+Ku+\sum_jB_j^TF_j=f,\qquad
\dot F_j=k_j[B_jv-g_j(F_j)],\quad
g_j(F)=c_j^{-1/\alpha_j}\operatorname{sgn}(F)|F|^{1/\alpha_j}.\tag{1}$$

沿u、v、F_j∈AC_loc、有限初态且输入局部可积的解，完整储能及功率为

$$E=\frac12v^TMv+\frac12u^TKu+\sum_j\frac{F_j^2}{2k_j},\qquad
\dot E=v^Tf-v^TCv-\sum_jc_j^{-1/\alpha_j}|F_j|^{1+1/\alpha_j}.\tag{2}$$

主体K的势能与支路弹簧能各计一次，两端一对力按一个相对位移端口计功。E0包括初始u、v和全部器件初力储能。若δj=Bju+dj(t)，必须另计ΣFj ḋj的支承功并重新认证预算，不能只补局部速度而沿用漏功能量。时变端口、随动几何、质量零DOF/DAE或其他端口也须先完成实际约束及功—能量处理。

R018的单调耗散证明允许全部正αj，未把αj>1时零点不局部Lipschitz的恢复项硬套通用Lemma。这里引用其已审解域，不增加新的存在性命题。

设f=b ag为一列实际共同输入，定义SK=ℓᵀK⁻¹ℓ。C≻0时再定义SC=bᵀC⁻¹b，并取全窗预算；无需C可逆的L1后备也列于下式：

$$\bar E_2=E_0+\frac14S_C\|a_g\|_{L^2(0,T)}^2,\qquad
\bar E_1=\left[\sqrt{E_0}+\frac1{\sqrt2}
\int_0^T\|M^{-1/2}f(t)\|\,dt\right]^2,
\qquad\sup_{[0,T]}|\ell^Tu|\le\sqrt{2S_K\bar E}.\tag{3}$$

Ebar可取适用且有限的任一预算，二者均适用时可取较小值。1/4来自实际背景C下的矩阵完成平方；L1形式来自零能量处的正则化估计，不需C可逆。多输入应保留完整矩阵二次型和共同输入，不把各方向独立当作同一标量ag。仅PGA而无时长或输入范数不能给此处数值；延伸自由尾也要确认全部外功输入确已停止。

| 退化/输出情形 | 必须保留的门槛 |
|---|---|
| C⪰0 | 用C†替代需f(t)∈Range(C)几乎处处及有限加权预算；不能漏掉ker(C)输入功。不满足时可核L1后备。 |
| K⪰0 | 该位移转换只对ℓ∈Range(K)可用K†；不能删掉刚体输出方向后仍声称原输出受控。 |
| M⪰0 | 不默认用M†。先处理实际约束/DAE；局部质量伪逆代数还要求Bj消去ker(M)，这本身不认证动力一致性。 |
| 绝对位移/其他输出 | 相对到绝对须加支承位移；层间差能否消去基底项取决于ℓᵀrg。绝对加速度、含器件力层剪不是式（3）换名。 |

## 3 完整能量到器件总速度与力

同一完整预算E(t)≤Ebar覆盖整个窗口时，定义局部质量对偶ηj、速度界Vbarj、储能力界Aj及平衡幅Peq,j：

$$\eta_j=B_jM^{-1}B_j^T,\qquad
\bar V_j=\sqrt{2\bar E\eta_j},\quad
A_j=\sqrt{2k_j\bar E},\quad P_{{\rm eq},j}=c_j\bar V_j^{\alpha_j},
\qquad
\sup|B_jv|\le\bar V_j,\quad
P_j:=\sup|F_j|\le\min\{A_j,\max(|F_j(0)|,P_{{\rm eq},j})\}.\tag{4}$$

Vbar控制串联总端速度，不是黏壶内部速度。只有动能预算时速度桥接仍可用，但不能据此取得Aj，因为器件初始/后续弹簧储能未必被它包含。非零初力须保留式（4）的初值项；不能用零速度阈值把已有器件力判为零。

零初力、有限T且Vbarj>0时，比较解有限窗严格低于Peq,j，但储能项仍只是Pj≤Aj，不能把整个min式一律改成严格号。Vbarj=0且零初力时Pj=0，不写“小于零”。真实器件参数与单位、连续端口速度和完整预算未经认证时，不输出工程峰力数字。

完整质量归一基给ηj=ΣrHjr²，**没有1/ωr²频率分母**。它只需质量完备性，不因此使有限Ritz子空间成为后文逆谱分解所需的确切Eigen子空间。可用保持同一约束坐标的质量求解Mx=Bjᵀ计算ηj，或给独立认证上界后作保守代入；仅截断H平方和是下估。本文件不新增η的精细尾界。

## 4 完整模态公式与有限保留的认证尾项

设完整实基Φ满足ΦᵀMΦ=I、Kφr=ωr²Mφr；若计算SC的对角正和，还要求**同一个完整基**使ΦᵀCΦ=diag(dr)，dr>0。定义

$$L_r=\ell^T\phi_r,\quad G_r=\phi_r^Tb,\quad H_{jr}=B_j\phi_r,\qquad
S_K=\sum_{r=1}^n\frac{L_r^2}{\omega_r^2},\quad
S_C=\sum_{r=1}^n\frac{G_r^2}{d_r},\quad
\eta_j=\sum_{r=1}^nH_{jr}^2.\tag{5}$$

一般非经典C要处理完整模态阻尼矩阵ΦᵀCΦ，不能逐阶对角取倒数。重频时，存在共同基不等于导出的刚度振型已共同对角化C；仅在真实Rayleigh背景或该簇阻尼相同等已核条件下可免除此旋转歧义。FNA有效/参考刚度不能未经证明替代分离支路后的物理主体K。

只保留部分正和会低估SK、SC、η，从而缩小声称的上界。R020的有限接口只针对SK/SC：保留模态须为确切、质量正交归一的Eigen子空间；给认证总量上界L0≥ℓᵀM⁻¹ℓ、G0≥bᵀM⁻¹b，并给覆盖**全部遗漏模式**的正下界ωr≥Ω>0、dr≥dtail>0。则

$$R_\ell=L_0-\sum_{ret}L_r^2\ge0,\qquad
R_b=G_0-\sum_{ret}G_r^2\ge0,\qquad
S_K\le\widehat S_K=\sum_{ret}\frac{L_r^2}{\omega_r^2}+\frac{R_\ell}{\Omega^2},\qquad
S_C\le\widehat S_C=\sum_{ret}\frac{G_r^2}{d_r}+\frac{R_b}{d_{tail}}.\tag{6}$$

残余是尾平方和的上界，不必等于真实尾量。将两个非负上估代入式（3）的Ebar2及位移界，方向安全；单有它们仍不补足初态、输入和外功预算。

尾项证据与数值门如下：

- 仅在确实保留排序前m阶时，最后保留频率才可作全部尾频率下界；任意高频子集不能这样用。跨重频簇允许等号，不需要假造谱隙。普通近似Ritz/Rayleigh根通常是谱值上估，不能反作安全下界；即使另给真Ω，也不自动修复Ritz逆谱拆分。
- 若已证尾ζr≥ζmin>0，可用dtail=2ζminΩ。若实际背景已核C=αRM+βRK、系数非负，可用严格正的αR+βRΩ²；这些Rayleigh系数不是器件指数αj。设计百分比或保留阶阻尼不认证全部高阶下界。
- 有效上界和确切正交项应使残余非负。负残余不能直接max(R,0)。有严格舍入/区间证据时，残余用总量上包络减保留平方和下包络，保留加权贡献另取上包络，分母用认证下界；定向舍入也不修复近似模态的不变子空间缺口。
- 无遗漏时完整求和；无保留时须有全谱下界。精确零残余不豁免SPD、共同基和输入门。本正下界合同不自动扩展为PSD合同，不能删零模态或写0/0。

地震相对坐标若已核b=−Mrg，则G0可由同向总质量rgᵀMrg的认证上界取得；裸影响向量rg不能直接代b。输入参与率即使高，也不能代局部输出的Rℓ或端口η证据。

## 5 CSI参与列：先认证字段，再选择转换分支

若原形状ψr与可信mr=ψrᵀMψr使用同一缩放，φr=ψr/√mr，故Lr=ℓᵀψr/√mr、Hjr=Bjψr/√mr。mr>0及节点形状缩放必须先核；若已质量归一，不再重复除质量。输入转换则按**已经确认的列语义**选择：

| 已确认的参与列定义 | Gr=φrᵀb，b=−Mrg时 | 不可重复的处理 |
|---|---|---|
| Γr=(ψrᵀMrg)/mr | −√mr Γr | 仅此定义使用该乘法 |
| Qr=ψrᵀb | Qr/√mr | 不套Γ分支 |
| γr=φrᵀMrg | −γr | 已质量归一，不乘√mr |
| fr=φrᵀmacc且已核macc=b | fr | 荷载已带负号，不再反号或乘√mr |
| 有效参与质量/参与率等平方量 | 不能单独恢复带符号Gr | 不靠开平方补相位 |

[CSI字段与归一化审查](../research/roles/literature/maxwell-session004/R009-modal-normalization-interface/R009-modal-normalization-interface.md)定位：CSI2016印pp375–376/PDF397–398明确最终Eigen/Ritz形状质量归一及参与因子点积；印pp338–339/PDF360–361的Acceleration Load已含d’Alembert惯性负号；印p372/PDF394区分起始Ritz荷载/静力向量与最终模态。若实际列已确认属于该单位加速度荷载分支，Gr就是fr，不能再反号或乘√mass。

当前软件版本、Field Description、ModalMass/ModalStiff公式与节点形状缩放仍未认证。API只列返回数组不补字段定义；不能从ModalMass接近1、ModalStiff接近ω²或列名UX就倒推分支。GUI放大形状与内部参与列也可能不同缩放。优先补字段字典及一个可核样例，再按同一Modal Case建立小表。

共同模态翻号时L/G/H应一起翻号；不可各节点独立取绝对值或重缩放。对纯轴向无偏置端口，Hjr由实际I→J轴与端点形状差投影；有刚臂/隔板约束则使用完整运动学。目标点、器件端点、输入b和背景C必须来自同一物理坐标与模型状态。

## 6 使用结果与来源边界

资料齐全时，可先核输入/E0得到全窗Ebar，再分别算固定位置位移系数SK、器件质量对偶ηj与初力项，形成条件保守证书。资料不齐时，交付的是保留模态参考和具体缺口，不填工程数字；补件不必升级为全楼节点时程，但完整性与尾谱证据不能省略。

粗能量预算在舍去全部器件耗散后，未提供布局排序。只改Bj时局部ηj可能变化，证书变化仍不推出真实峰值同序、楼层改善或最优布置。本文件不纳新合成布局候选的数值或定理。

**结论：CSI2016手册明确最终Eigen／Ritz振型质量归一，参与因子是振型与单位Acceleration Load的点积；该荷载本身已含d’Alembert惯性负号。当前表的ModalMass、ModalStiff却仍缺具体字段公式，不能凭列名或API签名认作任意缩放振型的广义质量／刚度。** 转换应先确认列属于哪一种归一与符号，再选下列代数分支。

## 1. 先固定一般代数，不把它冒充字段定义

设ψ_r是同一Modal Case、第r个最终模态的一致有符号原振型，m_r=ψ_rᵀMψ_r>0，且m_r与所有ψ分量使用**同一缩放、质量源及单位约定**。定义

\[
\phi_r=\psi_r/\sqrt{m_r},\qquad
L_r=l^T\phi_r=\frac{l^T\psi_r}{\sqrt{m_r}},\qquad
H_{jr}=d_j^T\phi_r=\frac{d_j^T\psi_r}{\sqrt{m_r}}.
\]

l是固定目标输出线性泛函；d_j是实际Link功共轭变形泛函。纯轴向、实际端点平移、统一全局坐标时，d_jᵀψ_r=e₁ᵀ(ψ_Jr−ψ_Ir)，e₁沿I→J；有约束、刚臂／偏置等时须按真实运动学映射，不能由Angle=0代替。固定点层间差需保留两点及高度，不能把逐时切换Label的最大漂移当固定l。

对指定平动地震输入方向向量r_g，采用相对坐标力型b=−Mr_g，G_r=φ_rᵀb。以下是不同的**列语义条件**：

|已由字段说明确认的输入列|质量归一G_r|注意|
|---|---|---|
|Γ_r=(ψ_rᵀMr_g)/m_r|−√m_r Γ_r|这是主控提出的常用原形状参与系数定义；只有列确实如此才用。|
|Q_r=ψ_rᵀb，未除模态质量|Q_r/√m_r|Q带原形状缩放，不能套上一行。|
|γ_r=φ_rᵀMr_g|−γ_r|该列已按质量归一；不再乘√m_r。|
|f_r=φ_rᵀm_acc，且已确认m_acc=b|f_r|CSI2016手册的单位加速度荷载定义属于此分支；负号已在荷载中，不再反号。|
|有效参与质量或质量参与率等平方量|不能单独恢复带符号G_r|平方量丢失符号，不能凭开平方补回相位。|

因此在Γ定义成立时，φᵀb=−√mΓ，正是一般代数所给；它**不是所有叫Participation的列的通用公式**。如果节点振型另被GUI放大／最大值归一，而输入列仍按内部质量归一输出，两列也不能不经映射混用。

一致重缩放ψ→sψ时，m→s²m、Γ→Γ/s、Q→sQ；φ及L/G/H只允许随s的符号共同翻转。不得独立取绝对值或各节点单独重缩放。产品LG、LH等在共同翻号下保持相容；当前研究需要的符号不能从质量参与率重建。

## 2. CSI原文直接核到什么

来源：CSI *Analysis Reference Manual*, July2016 Rev15，[官方原件](https://docs.csiamerica.com/manuals/etabs/Analysis%20Reference.pdf)，复用已有本地PDF，SHA256 `7f6f6890afee2e1890d33f5d34d53d8e23f60850890bd230848642b50a6291ac`，未重新下载。

|原文位置|直接定义及可用范围|
|---|---|
|印pp366–367/PDF388–389，Eigenvector Analysis|无阻尼自由振动广义特征问题；模态质量源及所取刚度状态须随Modal Case核对，不能混零初态／非线性末态。|
|印p372/PDF394，Ritz-Vector Analysis|起始载荷为动力荷载空间分布；首Ritz向量是静力位移，后续递推，再以特征求解技术正交化成最终Ritz-vector Modes，才各有振型／频率。起始载荷和首静力向量不是最终模态。|
|印pp375–376/PDF397–398，Modal Analysis Output／Participation Factors|输出说明同时适用于Eigen和Ritz；未编号式为f_xr=φ_rᵀm_x等，并明确φ_rᵀMφ_r=1。|
|印pp338–339/PDF360–361，Acceleration Loads|荷载按d’Alembert原理生成，节点平动荷载是相应质量的负值，经坐标变换装配；不能默认为正Mr_g。一般坐标／转动输入须按实际影响向量映射，转动参与报告以结构质心为参考。|
|印p377/PDF399，Participating Mass Ratios|方向质量参与率为f_xr²/M_x，总未约束方向质量M_x作分母；这是参与质量比例，不是当前表ModalMass字段字典。|

本轮已渲染并**实际查看**PDF361、394、397、398，确认惯性负号、Ritz阶段及质量归一原式。其余列页作文本复读。原文印p377称模态解释中参与因子的绝对符号不重要，不能据此在有符号响应重建时丢弃G与L/H的共同相位。

质量归一的理论基下，若最终模态同时对所用K对角化，广义质量为1、广义刚度为ω_r²。对任意一致缩放ψ则广义刚度k_r=ψᵀKψ，满足k_r/m_r=ω_r²。**这些是代数核对关系，不是本轮已证明软件ModalMass／ModalStiff一定输出这两个量。** 最终Ritz模态在其投影子空间内对角化，也不因此成为完整精确自然模态或给截断尾项证书。

## 3. 唯一官方查询与字段缺口

本轮仅1条CSI官方精准查询，取得[ETABS2016 API ModalParticipationFactors](https://docs.csiamerica.com/help-files/etabs-api-2016/html/eeed62fb-02ee-ccc7-294e-801669425bf0.htm)并读完整页。页面标明ETABS2016.dll Version16.0.0.0；方法返回Period、UX/UY/UZ/RX/RY/RZ、ModalMass、ModalStiff等数组。但Parameters仅列数据类型，没有给ModalMass／ModalStiff公式、单位、缩放、与数据库表／节点振型输出的映射解释。

故API证明字段存在，不足以补上字段原义。当前实际软件版本、具体Modal Participation Factors表的Field Description、节点模态振型的显示／数值缩放仍未知。不能从“ModalMass接近1”或“ModalStiff接近ω²”反向认证；也不能把ModalMass直接等同有效参与质量，把UX列自动等同常用Γ或G。

## 4. 单位、退化与最小补件

手册印p376说明T、循环频率f=1/T、角频率ω=2πf及特征值ω²。若T以s、f以Hz，则ω以rad/s；不得把Hz直接代ω，更不能把ω²再当ω。须看当前表单位和频率移位／静力修正等状态，不能仅凭列名猜。

m_r=0时不能作ψ/√m；负质量、零频／负特征值、静力修正及非普通动力结果另列核查，不能悄填零或套正频率常数。正定M的有效非零动力模态不应出现零广义质量，这个代数事实不能代替当前模型质量源诊断。

所有字段应统一到同一力—长度—时间制，并保存转动／平动坐标与输入方向。节点位移列的长度换算、模态质量所对应形状缩放及参与列的归一必须一致，不能仅将某一列除1000就假定整个接口已换算正确。

若可取得可信的同缩放m_r及输入列定义，建立L/G/H**不必默认索要全M**。最小补件为：

1. 当前软件版本、Modal Case及Eigen／最终Ritz类型，质量源、刚度初态／末态和实际求得模态标识。
2. 同一批最终模态的T或频率、目标固定点及各装置I/J实际端点的原始有符号振型；全局／局部坐标和真实I→J方向。
3. 与上述形状同缩放的m_r定义，参与列的公式／单位／惯性符号说明；若已质量归一，则确认该缩放与节点振型相同。

优先补当前版本Field Description和一个可核对样例，解决列映射；不是重复索取全质量矩阵，也不是只补一个没有符号的参与率。之后再按本报告分支转换。该接口仅确定保留基的投影，不认证模态数量充分、局部FNA收敛或全模态上界尾项。

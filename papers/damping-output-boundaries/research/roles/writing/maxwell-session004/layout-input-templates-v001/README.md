# 阻尼器布置小表填写说明

先填[装置位置表](device_locations.csv)，再填[属性表](link_properties.csv)。两份CSV现在都只有一行英文列名，没有示例、空白数据行或默认参数。从第二行开始填真实导出资料即可；只需装置及其端点，无需先提交全楼节点表。

## 先填哪些

装置表每只装置一行。先填唯一编号、属性名、I/J节点及各自XYZ、全局坐标系、长度单位、两端楼层、连接说明与资料来源。保留软件原I/J顺序；典型层图或截图只复查编号、漏项和连接关系，不能量取坐标。跨层、跨塔或同层不同隔板不能合并成一个楼层标签。

属性表按“属性名称＋工作DOF”一行，多只装置共用同一属性时只填一次；同一属性有多个工作DOF则分行。先明确工作分量及Link类型，再从原设置补非线性开关、本构类型、κ/c/alpha、各自单位及来源。有效刚度、有效阻尼是另外的设置，保持独立列，不能替代真实串联κ或非线性c。外部支撑/连接柔度是否另建模也须核查。

原生局部轴优先从模型导出，方向分量用全局坐标表达。零长或因舍入显示为零长的Link，必须提供对应工作方向的原生轴及来源，不能用端点差猜方向；轴向U1至少需完整局部1轴，其他工作分量按实际轴映射补齐。正常长度Link的几何方向也要与软件局部轴及结果方向核对。

未知数值留空，并在连接说明或备注写明待补项；空白不等于0。只在原记录明确为零时填0。未启用、不适用和未知分别说明，不能互相替代。不要从一个属性截图复制参数到其他属性；编号和节点ID导入Excel时按文本保存，避免丢失前导字符。CSV保存为UTF-8，含逗号的说明需按CSV规则加双引号，可用表格软件正常保存。

| 英文列名 | 中文含义 | 填写阶段与要求 |
|---|---|---|

| i_node_id | I端节点编号 | 定位必填，保留软件原端点顺序 |
| j_node_id | J端节点编号 | 定位必填，不按高低或坐标重排 |
| global_coordinate_system | 全局坐标系说明 | 定位必填，说明原点与轴方向，所有坐标统一 |
| length_unit | 坐标长度单位 | 定位必填，不猜测单位 |
| i_x | I端全局X坐标 | 定位必填，从模型导出 |
| i_y | I端全局Y坐标 | 定位必填，从模型导出 |
| i_z | I端全局Z坐标 | 定位必填，从模型导出 |
| j_x | J端全局X坐标 | 定位必填，从模型导出 |
| j_y | J端全局Y坐标 | 定位必填，从模型导出 |
| j_z | J端全局Z坐标 | 定位必填，从模型导出 |
| i_story | I端所属楼层 | 定位必填；跨层分别填，非楼层节点按原模型标识并在连接说明解释 |
| j_story | J端所属楼层 | 定位必填；保留塔楼或隔板区分信息 |
| connection_notes | 连接说明 | 定位时填写直连、支架、斜撑中间短Link、刚臂或未知 |

| local_axis_2_x | 局部2轴的全局X分量 | 原生轴可得时填写；涉及该方向或完整轴映射时必填 |
| local_axis_2_y | 局部2轴的全局Y分量 | 与局部2轴另两分量成组填写 |
| local_axis_2_z | 局部2轴的全局Z分量 | 与局部2轴另两分量成组填写 |
| local_axis_3_x | 局部3轴的全局X分量 | 原生轴可得时填写；涉及该方向或完整轴映射时必填 |
| local_axis_3_y | 局部3轴的全局Y分量 | 与局部3轴另两分量成组填写 |
| local_axis_3_z | 局部3轴的全局Z分量 | 与局部3轴另两分量成组填写 |
| source_reference | 坐标及连接来源 | 定位必填，写模型版本、导出表名或文件及可定位编号 |

## 属性表英文列名对照

| 英文列名 | 中文含义 | 填写阶段与要求 |
|---|---|---|
| property_name | 属性名称 | 定位必填，与装置表一致 |
| working_dof | 工作自由度 | 方向识别必填，按软件原名保留U1/U2/U3或转动分量；每个工作分量一行 |
| link_type | Link属性类型 | 类型识别必填，抄软件原名称 |
| nonlinear_enabled | 非线性开关 | 定量分析必填，抄原设置；不由类型名称猜开启状态 |
| nonlinear_model | 非线性本构类型 | 定量分析必填，抄对应工作DOF的模型名称 |
| series_kappa | 串联刚度κ | 定量分析必填，填该DOF真实串联刚度，不填有效刚度代替 |
| series_kappa_unit | κ单位 | 与κ成对填写，按平动或转动分量原单位 |
| viscous_c | 非线性黏滞系数c | 定量分析必填，不从拟合值或截图推及全部属性 |
| viscous_c_unit | 非线性c单位 | 与c、alpha成对核查，指数改变可能改变单位，不只交数字 |
| alpha | 速度指数alpha | 定量分析必填，抄该属性真实设置 |
| alpha_unit | alpha单位说明 | 按原定义注明无量纲或原记录说明，不补假定参数 |
| effective_stiffness | 软件有效刚度 | 定量分析前保留实际设置，单列，不与串联κ混列 |
| effective_stiffness_unit | 有效刚度单位 | 与有效刚度成对填写 |
| effective_damping | 软件有效阻尼系数 | 定量分析前保留实际设置，单列，不视作非线性c或阻尼比 |
| effective_damping_unit | 有效阻尼系数单位 | 按该DOF和软件定义填写，不默认与非线性c单位相同 |
| parameter_source | 非线性参数来源 | 定量分析必填，说明κ/c/alpha各自来源；不同来源在同格逐项列明 |
| software_settings_source | 属性与有效设置来源 | 注明模型版本、属性名、工作DOF及导出表或设置位置 |
| notes | 属性备注及待补项 | 记录未知、未启用或不适用的原因，不用数字占位 |

## 定量分析时再补哪些

坐标和局部轴能定位装置与解释方向，不能单独判断某模态下是否激活或预测减震效果。研究振型时，再给相关模态在这些I/J端点的三向振型位移，并注明模型、模态工况、阶次、频率、归一方式与单位。只有已确认端点随刚性隔板运动时，才可用隔板平移、转角、参考点和约束关系映射；柔性隔板、支架内部节点不能直接套用。FNA的Ritz基须按实际类型注明。

定量比较仍需核实际模态/背景阻尼、主体与质量、参考刚度及参考系统、连接/支撑设置和输入初态。不能只凭坐标、某阶相对位移大或两方案同为5%就断言更好。力口径也需另核：内部轴力P、I/J端和符号、原生局部轴、总变形U1及单位、工况和共同时间轴；节点力、截面力或独立峰值不能直接替代同刻内部轴力。公平效果比较还需同主体、同输入、明确背景及约束的成对结果。

如补已有结果，沿用原清单优先补Story4、5、7的目标装置内部轴力与总变形，按工况拆表，保留所有输出时刻和原单位。缺记录不代表实际力为零；Story7/RH4X的K12完整例外仍保留。补结果不代替坐标/属性定义，也无需为本模板重跑求解器。

# C017的理想正黏滞网络实现：任意L>0的解析证明

2026-10-17 10:11—10:15 +08:00。主控限定5分钟纯解析；无新模型、数值、搜索或时程。两个子审分别核resolvent/积分及网络/共同基底坐标。未使用E009单位模型的数值器件系数，也不改此前冻结材料。

**结论：supported / proof-reviewed。对每个固定有限L>0、ζ>0，M=I、k=(1,1,L)的Cζ=2ζ√K都可精确实现为六条系数严格正的理想线性黏滞支路：楼层间1–2、1–3、2–3，以及三个楼层各到同一个共同移动基底。** 因此该结论适用于IVT定义的固定L*，不需要已知L*小数；但不能给L*挪用unit模型数值，也不是仅相邻楼层dashpot拓扑或实际装置建造结论。

## 1. Resolvent逐项严格正

固定

`K=[[2,-1,0],[-1,1+L,-L],[0,-L,L]], L>0`。

K=Bᵀdiag(1,1,L)B严格正定，且`K1=e₁`。对t≥0，记R(t)=(K+tI)⁻¹，精确分母为

`d(t)=t³+(3+2L)t²+(1+5L)t+L>0`。

其对称adjugate的上三角为

`adj₁₁=t²+(1+2L)t+L`，`adj₁₂=t+L`，`adj₁₃=L`，

`adj₂₂=(t+2)(t+L)`，`adj₂₃=L(t+2)`，

`adj₃₃=t²+(3+L)t+1+2L`。

所有项对每个t≥0均严格正，故R(t)逐项严格正。独立的结构证明是取a=trK，P=aI−K逐项非负且ρ(P)=a−λmin<a，Neumann展开`R=(a+t)⁻¹Σₙ≥₀[P/(a+t)]ⁿ`结合链连通性，同样给所有Rᵢⱼ>0。

## 2. 平方根的严格符号及积分收敛

令J为K的唯一对称正定平方根。由正谱逐项应用标量积分，

`J=(1/π)∫₀∞ t⁻¹/² K(K+tI)⁻¹ dt`。

该矩阵积分在0端为O(t⁻¹/²)，在∞端由KR=K/t+O(t⁻²)为O(t⁻³/²)，范数绝对收敛。

由KR=I−tR，对i≠j有

`Jᵢⱼ=−(1/π)∫₀∞t¹/²Rᵢⱼ(t)dt<0`。

这里0端R有界，改写后为O(t¹/²)；∞端非对角R=O(t⁻²)，为O(t⁻³/²)。1–3项实际衰减更快，但不需另用该加强界。严格负号来自每个t>0的Rᵢⱼ>0，不依赖浮点残差。

K与R交换，且K1=e₁，所以

`J1=(1/π)∫₀∞t⁻¹/² R(t)e₁dt`。

R第一列逐项严格正，故每个行和`(J1)ᵢ>0`。0端为O(t⁻¹/²)，∞端R=O(t⁻¹)给O(t⁻³/²)，亦绝对收敛。没有把一般SPD平方根误当成逐项正矩阵；所需的是本K的resolvent和K1的特定符号。

## 3. 六支路分解与被动耗散

取C=2ζJ。定义三个楼层间系数与三个共同基底系数

`cᵢⱼ=−Cᵢⱼ>0 (i<j)`，`gᵢ=(C1)ᵢ>0`。

它们均为有限实数，并且精确有

`C=diag(g)+Σᵢ<ⱼ cᵢⱼ(eᵢ−eⱼ)(eᵢ−eⱼ)ᵀ`。

非对角项为−cᵢⱼ=Cᵢⱼ；对角项为`gᵢ+Σⱼ≠ᵢcᵢⱼ=Cᵢᵢ`，所以六支路无遗漏。特别c₁₃严格正，无法把此分解称作只含相邻层连接的三对角网络。

若需L*的精确器件定义，可直接取以上积分在L=L*的值；这是严格定义而非数值标定。本轮不给L*任何器件小数，也未求最优/最少支路配置。

对相对速度v，网络耗散率为

`vᵀCv=Σᵢgᵢvᵢ²+Σᵢ<ⱼcᵢⱼ(vᵢ−vⱼ)²≥0`，

非零v时因所有gᵢ>0而严格正。因此每支路均为普通被动线性黏滞元件，不需主动负阻尼。ζ增加Δζ≥0时，每个cᵢⱼ与gᵢ都同比非减；Δζ>0时全部严格增加，且`ΔC=2ΔζJ`严格正定。5%→8%对应所有六系数乘8/5。

## 4. 共同移动基底保持原基底加速度输入

设绝对楼层位移为x，所有接基底支路共同支承位移为qg(t)，令`u=x−1qg`。楼层间支路速度为`ẋᵢ−ẋⱼ=u̇ᵢ−u̇ⱼ`，接基底支路速度为`ẋᵢ−q̇g=u̇ᵢ`。

绝对坐标中阻尼力为`Cẋ−gq̇g=C(ẋ−1q̇g)=Cu̇`，因为g=C1。原弹簧以同一基底为支承，也恰给Ku。因此运动方程变为

`Mü+Cu̇+Ku=−M1q̈g`，

与C017的共同基底加速度输入完全一致，无额外基底速度项。若某接基底支路改接惯性固定地，不能沿用这一输入等价。本证明要求的是同一共同移动支承，不声称任意固定地面布置等价。

有基底输入时，外部支承可输入机械能；支路耗散非负不等于受迫结构机械能单调下降。这里只确认理想黏滞网络的被动耗散与模型等价。

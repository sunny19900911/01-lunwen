## 精确可用命题

设ω1≠ω2>0、实留数r1,r2不全为零、0<ζ0≤ζ1；两状态质量、刚度、输入方向和实线性位移/恢复力输出保持不变，阻尼均为每阶相同ζ的经典阻尼。输入f可取任意同一实紧支撑L1函数（平移时间使支撑起于0），初始状态为零。取包括全部自由衰减尾段的全时程输出，令κ=ζ1/ζ0，则

`||y1||∞ <= (4κ−3)(5−4/κ)^2 ||y0||∞`。

两稳定因果冲激响应有界且L1，故这些L1输入的输出确实有界。若f=0，不等式仍成立但不能报告比值。任一非零紧支撑输入和非恒零H0给||y0||∞>0，此时可报告比值。还可通过有限测度与L1核的卷积恒等式，把不等式扩到有界输入；首版建议保留紧支撑L1量词，不必扩展正文。

输出不含随ζ变化的阻尼力系数或绝对加速度直接输入项。若使用非零初始状态，y1=Q*y0的纯输入传递关系一般不成立，需要另计初始响应。

## 独立证明核查

记`Dj,k=s²+2ζkωj s+ωj²`，`Nζ=a s²+2ζb s+c`，其中a=r1+r2、b=r1ω2+r2ω1、c=r1ω2²+r2ω1²。直接整理得

`c=(ω1+ω2)b−ω1ω2a`。

因此非零传递时，a=0必有b≠0，且c/b=ω1+ω2>0；a≠0时若c/a>0则b/a>0。两个阻尼状态的分子次数一致，故`Q=H1/H0=(N1/N0)∏(Dj,0/Dj,1)` proper。其虚轴非零零点不可能存在；原点零点必须在两状态间同时出现并可约去。这些特殊结构是双模态结论的关键，不能无条件推广到三模态。

对`Rαβ=s/(s²+2αs+β)`，独立核查如下。

1. β>0、α>0欠阻尼：其核k=e^(−αt)(cosγt−αsinγt/γ)，t≥0。使用|sinγt|≤γt可直接得∫|k|≤1/α+1/α=2/α，不需在γ→0时除以小量作粗估。
2. β=α²临界：核e^(−αt)(1−αt)的绝对积分为2/(eα)，与上界相容。
3. 0<β<α²过阻尼：令根为−p、−q，0<p<q、q≥α。位移核g=(e^(−pt)−e^(−qt))/(q−p)非负单峰，两端为0。卷积表示g=e^(−pt)*e^(−qt)给maxg≤1/q，因此∫|g'|=2maxg≤2/q≤2/α。未将欠阻尼公式硬套到过阻尼。
4. β<0：令d=√(α²−β)、p=d−α>0、q=d+α>0。R=p/(p+q)/(s−p)+q/(p+q)/(s+q)。对右半平面极点取反因果核−e^(pt)1[t<0]，对左半平面极点取因果核e^(−qt)1[t≥0]。两半轴支撑分开，核绝对积分恰为2/(p+q)=1/d。此式对α=0也成立。
5. β=0时先约去s，得到1/(s+2α)，核范数为1/(2|α|)。若α=0且β≠0，对分子比实际有修正系数α=0，N1/N0=1，不应写0乘一个无界核；对双模态β>0、α=0由系数关系已排除。

当a≠0，令α=ζ0b/a、β=c/a，分子比为`1+2(κ−1)αRαβ`。β>0时有限测度TV≤1+4(κ−1)=4κ−3；β<0且α≠0时TV≤1+2(κ−1)|α|/√(α²−β)≤2κ−1；β=0时TV≤κ；b=0直接为恒等因子1。a=0时

`N1/N0 = κ−(κ−1)p/(s+p), p=(ω1+ω2)/(2ζ0)>0`，

直通项是κ而不是1，TV=2κ−1≤4κ−3。这里δ与连续核互相奇异，TV相加合理。

每个模态比`Dj,0/Dj,1=1−2ζ1ωj(1−1/κ)Rζ1ωj,ωj²`，同一核引理给TV≤5−4/κ。有限测度卷积的TV次乘性即给B。

最后，q取上述双边有限测度。q*h0和h1均为L1核，傅里叶变换恒等式QH0=H1与L1傅里叶唯一性给q*h0=h1；由Fubini与卷积结合律得y1=q*y0，再应用全实线L∞卷积不等式。此证明不要求H0为最小相位，也不把稳定双边逆误称为稳定因果逆。

## 边界裁决

| 情形 | 审核结果 |
|---|---|
| ζ1=ζ0 | Q=1，B=1，输出相同 |
| r全零或H0恒零 | 排除；非零测量向量本身不够，见helper-double-mode.md最小例 |
| 单留数为零 | 可约为单模态，粗界仍成立 |
| 同频ω1=ω2 | 合并为单模态；若r1+r2=0则恒零，否则可用模态因子界；原I001保留异频假设即可 |
| a=0 | 线性分子，直通项κ，已单独审核 |
| b=0 | N1=N0，右半平面零点完全相消，不产生Q极点 |
| c=0 | 共同原点零点消去，其余一阶极点在左半平面 |
| 非最小相位H0 | 允许；使用反因果分量约束完整输出，需要未来y0信息 |
| 截断同一观察窗 | B不能直接套用；反因果核会用窗外未来y0 |
| Q有虚轴未消极点的一般多模态 | 无双边L1核；与三模态无界例相容 |

`proper`对固定有限观察窗的因果卷积估计足够（局部可积核可有右半平面或虚轴极点），但不是全时程稳定核的充分条件。若Q有右半平面极点，因果有限窗常数可随T指数增长；若有p阶虚轴极点且无更不稳定极点，可出现T^p规模。一般多模态Q还可能improper，须另行检查，不能只凭两个原系统稳定就默认其比值proper。

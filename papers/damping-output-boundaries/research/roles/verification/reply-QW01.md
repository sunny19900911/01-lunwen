# 给作者的QW01/QW02答复：可入正文条件与定位

## C001：双模态有限变化判据

可采用的精确版本：两个不同正固有频率ω1、ω2，固定实留数r1、r2不全为零，固定Ω>0，0<ζ0<ζ1，各阶阻尼比同步取ζ，输入分布、质量、刚度与实线性位移/恢复力输出不变。定义原理论稿第4节的A、B、C、D、E及xk=ζk²，则有限增阻尼谐波幅值增加当且仅当

`BC−AD−AE(x0+x1)−BE x0x1 > 0`。

此处至少一个“有效模态留数”非零，不能只写测量向量ℓ≠0。行列式`2Ω(ω2−ω1)(ω1ω2+Ω²)≠0`保证A、B不同时为零，也保证基准谐波输出不为零，故比较和x_cross均有定义。完整代数证明和1080组有理数精确检查见`helper-double-mode.md`的V-DM-01/02。

| 退化/边界 | 正文可以准确写什么 |
|---|---|
| B=0 | A>0，F(x)在x>0严格递减；不用x_peak的除B公式 |
| C=0，即Ω为某固有频率 | ζ0>0下模态分母仍严格正，有限变化判据有效；反共振闭式边界要求C>0，不能使用 |
| A=0 | B>0；仅当C>0时有原稿式(13)的反共振峰值和乘积判据 |
| 同频 | 合并为单模态；合并留数非零时幅值严格随ζ降低，合并留数为零时传递恒零；原双模态x_cross/锐性论证不直接套用 |
| 输出恒零 | 不报告0/0比值或x_cross，单列为排除情形 |
| 基准频点H0=0 | 上述非平凡异频双模态且Ω>0、ζ0>0的前提已排除；三模态可以发生，不据双模态分母非零推广 |
| Ω=0 | 静力传递不随ζ变，若静力输出为零则比值无定义；不代入含Ω正因子的推导 |
| ζ0=0 | 不在本版定理内，模态极点/反共振比值需另审 |

原稿式(14)严格谐波上界`|H1|/|H0|<κ`有效；对非零L2输入、零初始和完整输出也可用严格L2上界。它不等于L∞峰值界。

## C002：留数符号和抵消界

同号版本：任意有限模态数、ωi>0、固定Ω>0、实留数的所有非零项同号且至少一项非零、0<ζ0<ζ1、固定实位移/恢复力输出及固定输入分布，得到`κ^−1≤|H1|/|H0|≤κ`。证明因`−ImH>0`排除该频点零输出，允许对log|H|积分。**同号不是幅值单调下降的条件**；`helper-double-mode.md`的V-DM-03给同号却增加的两模态最小例。

异号版本：对同一频率的正负留数群定义H+、H−，并要求基准H0≠0，即χ0>0，才可写`|H1|/|H0|≤κ/χ0`。若χ0=0，应回到不含除法的不等式，不能给有限比值界。完整L2版本使用全尾段、同一L2输入及输出群的L2范数χ2,0；不能将某时刻楼层力抵消系数或有效质量比例当作χ。

这些条件见原理论稿第2/3节，以及`round-001.md`的量词审核；不需要ζ<1限制，过阻尼系统同样稳定。输出带ζ相关阻尼力项或绝对加速度直接项时，不能未经重推沿用。

## QW02：有限峰值量词与新粗界

- V001/原定理4：固定三模态系统和输出，存在随T改变持续时间与相位的输入族，每次输入紧支撑且有界，完整峰值比无界。固定同一480 s输入、只延长观察尾段100/200/400 s的实算比值相同，见`round-001.md`。
- V002/新I001：双模态对每个相同紧支撑实L1输入、零初始、完整尾段有`||y1||∞≤(4κ−3)(5−4/κ)^2||y0||∞`；本角色给proof-reviewed，尚待主控登记。非最小相位用稳定双边核，因此不将该B用于截断同窗峰值。
- 固定同窗：若Q=H1/H0 proper，用其因果核可得依赖窗长的B_Q(T)。即使原H0、H1稳定，Q也可有不稳定/虚轴极点；常数可能随T显著增加。

三条可共同写成输出定义与输入量词清楚的分类，不能把“同一输入在两个阻尼状态比较”误读为“所有T使用同一条输入”。工程原生净力/加速度的配对结果不构成V002或任意留数模型的验证。

## 1. 欠阻尼精确范数

令 ω=√β、γ=√(β−α²)>0，位移核 g(t)=exp(−αt)sin(γt)/γ，t≥0；g(0)=0，g′(0)=1，R∨=g′，不存在由延拓产生的 δ，因为 g(0)=0。

取 θ=arctan(γ/α)∈(0,π/2)，首个正极大值时刻 t*=θ/γ。全部极值时刻为 t*+nπ/γ，极值依次为 (−ρ)ⁿM，其中 ρ=exp(−πα/γ)∈(0,1)，M=exp(−αt*)/ω。核的总变差为

`TV(g)=M+Σ(n≥0)(Mρⁿ+Mρⁿ⁺¹)=2M/(1−ρ)`。

这包含首段从0升至M和全部尾段；不能漏掉首段或把衰减振荡当单峰。

令 z=α/ω∈(0,1)，因 sinθ=γ/ω，θ≥sinθ 给 t*≥1/ω；π≥2sinθ 给 π/γ≥2/ω。两步不等式方向分别意味着 exp(−αt*)≤exp(−z) 和 ρ≤exp(−2z)。所以

`α TV(g) ≤ 2z exp(−z)/(1−exp(−2z)) = z/sinh(z) < 1`。

这套外包在 z→0 时趋1，不表示欠阻尼真实范数达到1；例如其真实极限为2/π。本轮无需欠阻尼最优常数。

## 2. 临界与过阻尼

临界时 g=t exp(−αt)，单峰位于t*=1/α，故 TV(g)=2/(eα)<1/α。

过阻尼令 p=α−√(α²−β)>0、q=α+√(α²−β)>p，则 g=(exp(−pt)−exp(−qt))/(q−p)>0，且 g′只有一个正零点，g两端均为0。因此 TV(g)=2gmax。对 t>0 的齐次ODE `g″+2αg′+βg=0` 从0积分到峰值时刻，使用 g′(0)=1、g(0)=0、g′(t*)=0，得到

`−1+2α gmax+β∫₀ᵗ* g(t)dt=0`。

末项严格正，所以 gmax<1/(2α)，TV(g)<1/α。相同积分也可覆盖临界分支。没有遗漏外力 δ：这里是在 t>0 的齐次方程使用右初值，而不是把分布方程再次积分而重复计入冲量。

## 3. β→0⁺ 的锐性与端点

固定α>0，令β↓0。过阻尼峰值 t*=log(q/p)/(q−p)，且 gmax=exp(−pt*)/q。此时 p→0、q→2α、pt*→0，故 αTV(g)→1。于是统一常数1不可缩小。

β=0本身必须先约去s：R=1/(s+2α)，因果范数仅1/(2α)。这与 β↓0 的 L1 范数极限不同：极限过程中一个远尾段的变差并未在任何固定时间窗收敛中保留。因此不应以 β=0 代替正 β 极限论证。

## 4. 双模态所有分支

仍取 V002 的固定实留数、异频正ω、统一经典模态阻尼、0<ζ0≤ζ1、κ=ζ1/ζ0、零初始及完整时程量词。令 Nζ=a s²+2ζbs+c，约束 c=(ω1+ω2)b−ω1ω2a。

| 分支 | 正确处理及分子比的TV上界 |
|---|---|
| a≠0，β=c/a>0 | 结构保证 α=ζ0b/a>0；N1/N0=1+2(κ−1)αR，得 ≤2κ−1 |
| a≠0，β<0 | d=√(α²−β)>|α|；双边稳定R核范数=1/d，得 ≤1+2(κ−1)|α|/d≤2κ−1；若α=0直接恒等 |
| a≠0，c=0 | 公共s约去，结构给α>0；比值为1+2(κ−1)α/(s+2α)，TV=κ≤2κ−1 |
| a≠0，b=0 | 分子比恒为1；不可对虚构未消极点强行套核范数 |
| a=0 | 非平凡时b≠0，p=(ω1+ω2)/(2ζ0)>0；比值 κ−(κ−1)p/(s+p)，TV=2κ−1 |
| a=b=0 | 约束强制c=0；异频意味着两留数均零，须排除H0恒零 |
| 单留数为零 | 可约为一个模态因子，界仍适用 |
| 同频 | 先合并留数；和为零则恒零，否则单模态因子界≤3−2/κ≤B(κ) |
| κ=1 | 两输出相同，B=1 |

每个模态因子 D(j,0)/D(j,1)=1−2ζ1ωj(1−1/κ)R，其中α=ζ1ωj>0、β=ωj²>0，故TV≤3−2/κ。有限测度TV的卷积次乘性给 B=(2κ−1)(3−2/κ)²。全部TV相加都计入直通δ；a=0的直通项确为κ。

β<0的R使用左/右半轴稳定核，不要求最小相位。沿用 V002 已列明的傅里叶唯一性和卷积结合律，完整输出满足 y1=q*y0；该精化没有把双边重构变为因果重构，不能移植到同一截断观察窗。比值还要求基准峰值非零；紧支撑非零输入和非恒零H0保证这一点。含随阻尼变化的输出系数、绝对加速度直通项或非零初始不在原命题内。

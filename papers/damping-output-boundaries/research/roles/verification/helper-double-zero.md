## V-DZ-01：双重零点

设 `D_i(s)=s²+2 zeta omega_i s+omega_i²`。合并分子由独立多项式乘法计算为

`N_zeta(s)=sum_i r_i product_{j != i} D_j(s)`。

精确分数长除核验：基准分子被 `(s²+4)²` 整除，四项余数均严格为零；其剩余四次商在 `s=2i` 的值为

`79281644855562/5 + i 15292723924368/5 != 0`。

所有 `D_i(2i)` 非零（正阻尼且频率正），所以分子因子确为传递函数在 `s=2i` 的二重零点，而非分母造成的伪约分。傅里叶频率变量的两项零条件相应成立，且不是三重或更高阶。

新增阻尼状态独立求得：

`Re H1 = -913587513300/416768604484467859`，

`Im H1 = 191407728404504439/1687079310953125893232`，

`|H1| = 0.00011347626068412992`。

这是给定见证的精确代数审核；没有复算“所有四模态都不可能”的命题，也没有由4条约束直接宣布最小模态数。

## V-DZ-02：零延拓的全时程二阶余项

定义 `a(x)=sin⁴(pi x/2)`，`0<=x<=2`，其余为零，并置 `a_T(t)=a(t/T)`。

端点附近 `a(x)=O(x⁴)`，故零延拓至少为全局 `C³`，特别是全局二阶Taylor余项适用。区间内

`a(x)=(3-4 cos(pi x)+cos(2 pi x))/8`，

故 `||a'||_infty <= 3 pi/4`、`||a''||_infty <= pi²`。端点外导数为零，端点导数连续，不产生分布型脉冲。

由 `H0(2)=0` 和 `H0'(2)=0` 得

`integral h0(s) exp(-2is) ds = 0`，

`integral s h0(s) exp(-2is) ds = 0`。

因此对复输入 `a_T(t) exp(2it)`，在卷积中减去 `a_T(t)-s a_T'(t)`，得对所有实数t（包括输入结束后的尾段）

`|Y0(t)| <= pi² m0,2 / (2 T²)`，

其中 `m0,2=integral s² |h0(s)| ds`。这一界成立的关键是全局零延拓与二阶导界，不能只在窗内使用Taylor展开而遗漏尾段。

对新状态，单次Lipschitz余项给出 `|R1(t)| <= (3 pi/(4T)) m1,1`。选择实输入

`f_T(t)=a_T(t) cos(2t+theta_T)`，`theta_T=-2T-arg H1`，

则 `|f_T|<=1`，每个输入的支撑均为有限区间 `[0,2T]`，并且同一输入分别作用于两阻尼状态。于 `t=T` 有

`P1 >= |H1| - 3 pi m1,1/(4T)`。

基准系统非恒零有理传递函数对该非零有限支撑输入的输出不恒零，故 `P0>0`。从而

`P1/P0 >= [2 |H1|/(pi² m0,2)] T² - [3 m1,1/(2 pi m0,2)] T`，

在右端为正时为有效下界。这是输入族的存在性和增长下界，不是对任意输入的上界，也不是已运行的峰值时程数值实验。

## V-DZ-03：矩界的独立重算

对当前欠阻尼参数，逐模态冲激响应为

`h_i(t)=r_i exp(-zeta omega_i t) sin(omega_i sqrt(1-zeta²)t)/(omega_i sqrt(1-zeta²))`。

使用三角不等式、`|sin|<=1` 和指数矩积分，独立得到

`m_k,p <= sum_i |r_i| p! / [omega_i sqrt(1-zeta_k²) (zeta_k omega_i)^(p+1)]`。

## 1. 精确差值身份、初态与模态质量

同一约束后坐标中，固定同一 M≻0、K≻0、C、外力 f 及主体初始位移/速度，设 U 去掉全部指定支路，D 的左端器件项为 +BᵀF_D，其中 δ=Bu、F_D 是功共轭完整恢复力历史。则 w=u_D−u_U 严格满足

\[
M\ddot w+C\dot w+Kw=-B^TF_D,\qquad w(0)=\dot w(0)=0.
\]

同 f 消去不表示两条轨迹的输入功或总能量相同。器件初力若非零，已通过真实 F_D 对主体施力；在主体初态相同的前提下，不应再叠加一次器件初力的主体齐次项。

若完整确切 Eigen 基满足 ΦᵀMΦ=I、ΦᵀKΦ=diag(ω²)，且同一基中实际 C 为 diag(2ζω)，则 γ_j=ℓᵀφ_j、β_dj=B_dφ_j，固定线性位移/相对位移输出 y=ℓᵀu 满足

\[
y_D-y_U=-\sum_{j,d}\gamma_j\beta_{dj}(G_j*F_{D,d}).
\]

对 ω>0、0≤ζ<1，所列 G=e^(−ζωt)sin(ωsqrt(1−ζ²)t)/(ωsqrt(1−ζ²))（t≥0）具有 G(0)=0、G'(0+)=1，t>0 满足齐次标量方程；零初态 Duhamel 积分正确。局部可积真实力足以在有限窗内建立身份。ζ=0 仍有此有限窗身份，但 G 不属于无限时 L1，不能据此套用无限时 Young/BIBO 增益。过阻尼、临界阻尼或非经典 C 需另用适用核/矩阵算子，当前欠阻尼标量式不直接覆盖。

任意未归一形状 ψ_j 必须是上述共同正交模态的一致逐模态缩放，m_j=ψ_jᵀMψ_j>0。相应系数为 (ℓᵀψ_j)(B_dψ_j)/m_j，不能遗漏 m_j，也不能用于任意非正交基。ψ_j→sψ_j 时两个投影乘 s、质量乘 s²，因此任意非零实缩放和模态翻号不改变结果；重频簇仍需共同对角化实际 C 并一致变换投影。显示归一振型、别的缩放下质量列或质量参与率不得拼接。

## 2. 符号、端口与数据闭合

负号来自 D 方程左端的 +BᵀF_D。若改变端口约定 B_d→−B_d，必须同时 F_d→−F_d 才保持装配和贡献不变。实际交换 I/J 还可能改变局部轴，不能机械地只反一列；有偏置、转角、刚臂和约束时须由实际运动学重建 B。软件 P 列是否等于该恢复力、哪个端点/方向、符号、单位与缩放，都需字段或校准证据。纯轴向无偏置情况下的端点差只是特例。

完整模态集合 J、器件集合 D，只保留 I×S 时，遗漏集合应精确分拆为

\[
(J\setminus I)\times D\quad\cup\quad I\times(D\setminus S).
\]

两集合不重叠，并与 I×S 一起覆盖全体。R022 的余项因此正确；不能把缺模态与缺器件的交叉项漏掉或重复加入。有符号贡献可以相消，部分和没有天然的总差上/下界。现有 32/88 只是同一 D 力轨迹中的部分贡献，另 56 只必须留项；它也不等于“实际移除这32只”后的反事实响应，因为其余器件力通常改变。

有限窗 Young 上界在已认证遗漏投影、核范数和真实力范数时可用；这些量未知时不得补零。质量参与率、器件数量/耗能比例、不同模型旧300阶表，均不能补成有符号时程余项证书。近似 Ritz 还需投影与动力残差，不能冒充完整确切 Eigen 尾和。

采样力 Fhat 的卷积重构还缺 G*(F_D−Fhat)，时间轴、插值与求积误差必须另核。外部输入停载不说明 Maxwell 力同时为零；历史截止后的力与响应不能自动延伸为全时结论。有限时位移差身份也不会自动给出两条绝对响应或各自真实峰值。

## 3. FNA：参考算子、残余力和反事实基线必须成套

复用角色3已读 CSI Rev15 原页的冻结转录与范围，本轮未新读 PDF 或声称自己看过原页。CSI 定义 K_ref=K_L+K_N、右端非线性项 −[r_N−K_Nu]，背景模态阻尼假设相对于包含有效刚度的总 K。逐器件 F−k_eδ 是在已核 r_N=BᵀF、K_N=Bᵀk_eB 后的条件装配代数，不是软件输出列的直接定义。

令 L0=M D²+C D+K0，L_eff=L0+Bᵀk_eB，R_D=F_D−k_eBu_D。在保持同一 M/C 的条件下，

\[
L_0u_D=f-B^TF_D,\quad L_{eff}u_D=f-B^TR_D.
\]

完整 F_D 配物理裸 K0；残余 R_D 配 K_eff。后者若只删去右端残余，对应的是 L_eff u_Ueff=f，基线通常不是 L0u_U0=f。比较物理裸主体必须用

\[
L_{eff}(u_D-u_{U0})
=-B^T R_D-B^Tk_eBu_{U0}
=-B^T(R_D+k_eBu_{U0}).
\]

额外补偿的负号正确。直接把 K_eff 与完整 F_D 混配，或把 K0 与残余力混配，都改变了原平衡关系。k_e 是参考有效项，不是实际串联 κ；单个 DOF 的 k_e=0 不推出全部 K_N=0、真实 F_D=0 或实际 κ=0。CSI 此处残余不擅自增加 Link 线性有效阻尼补偿。

更换 K_eff 为 K0 后，不能继续搬用原 FNA 的 Φ、ω、ζ 并默认实际 C 仍被对角化。两边都填5%也不能证明实际 C 相同；改变建基刚度并按同一 ζ 重建 C，通常已改变物理算子。固定矩阵参考卷积可有定义，但当前标量模态公式仍须重新核所选参考的完整共同基。

去掉指定非线性 Maxwell 支路不自动等于删除整只 Link。CSI 的 K_L 包括 Link 线性 DOF；若删除单元还改了线性 DOF、质量、约束等，就须保留对应算子差异项。一般相异主体还会出现 Δf−ΔM uD''−ΔC uD'−ΔK uD、初态齐次项及其他未列非线性余力。

## 4. 最小接口与解释边界

R022 minimum-fields.json 对本条件差值接口已包含必要门：参考模型/约束/质量源/K与实际C身份；完整共同 Eigen/归一或明确余项；ω(rad/s)、实际 ζ、同缩放 m；固定 ℓ 与有符号 γ；全部指定端口 B/有符号 β 和共轭力映射；同一 D 工况的完整真实力或有误差认证的采样重构、时间窗和单位；同 f 及主体初态的证据。可直接交经认证局部投影，不必提供全楼其他节点，但不能因此豁免模态/器件完整性。

计算这个差值不另需共同外力的模态参与因子，仍须有同输入身份；恢复绝对 y_D 还需 y_U 或独立的参考输入/初态解。给定同源真实 F_D 之后逐核叠加属于条件重构；F_D 仍受 D 中所有模态和器件反馈。换布局或输入后的真实力未知，旧力移植只定义规定外力重放，不能认证新布局的被动响应，也不构成独立预测验证。

输出范围仅固定线性位移/相对位移；加速度和总层剪不能直接照搬该式。R022 与来源报告均未越过上述边界，经典 Duhamel/投影接口不作新理论、指标或首创主张。

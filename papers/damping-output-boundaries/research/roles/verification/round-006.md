## 1. 标量核与总变差

设g为`1/(s²+2αs+β)`的因果冲激响应，g(0)=0、g'(0)=1。R的普通因果核为k=g'。以下范数为∫0∞|k(t)|dt；α、β均严格正，分母极点均稳定。

### 欠阻尼：0<α<sqrtβ

记ω=sqrtβ、γ=sqrt(β−α²)、θ=arctan(γ/α)∈(0,π/2)、z=α/ω=cosθ。位移核为

`g(t)=e^(−αt)sinγt/γ`。

第一个正极值在t*=θ/γ，幅值为`e^(−αt*)/ω`；之后极值的符号交替，绝对值按ρ=e^(−πα/γ)衰减。从0到第一个极值贡献一次幅值，各后续单调段贡献相邻极值绝对值之和，故

`||g'||1 = 2e^(−αt*)/[ω(1−ρ)]`。

这里确实包括开始的半段与无穷尾段，不能只将第一正峰乘2而忽略后续振荡。

由θ≥sinθ、γ=ωsinθ，得t*≥1/ω，故αt*≥z；由π≥2sinθ，得πα/γ≥2z，故ρ≤e^(−2z)。不等式方向分别使分子不增、分母不减，于是

`α||g'||1 <= 2z e^(−z)/(1−e^(−2z)) = z/sinhz <1`。

最后一步由z>0时sinhz>z。这个直接几何级数证明不依赖猜想者随后给出的Cauchy路线。

### 临界阻尼：α=sqrtβ

g(t)=t e^(−αt)，k=e^(−αt)(1−αt)。于1/α变号，直接积分得

`||k||1 = 2/(eα) <1/α`。

### 过阻尼：α>sqrtβ

设p=α−sqrt(α²−β)、q=α+sqrt(α²−β)，0<p<q。g=(e^(−pt)−e^(−qt))/(q−p)≥0且单峰，两端趋0。故`||g'||1=2gmax`。在峰值时刻t*，对ODE从0积分：

`g'(t*)−g'(0)+2α[g(t*)−g(0)]+β∫0^t* g(t)dt=0`。

代入端点得到`2αgmax=1−β∫0^t* g<1`，从而`||k||1<1/α`。此法不在临界附近除以很小的q−p，也不将欠阻尼正弦公式用于过阻尼。

## 2. 标量常数的锐性及β=0警告

固定α>0，令β下降趋0但每次仍严格正。过阻尼峰满足

`gmax = (p/q)^(p/(q−p))/q`。

此时p→0、q→2α，且`[p/(q−p)]log(p/q)→0`，所以`α||k||1=2αgmax→1`。因此不能将标量引理的系数1统一换成更小正数。

在β**恰好等于**0时，R约去s后为1/(s+2α)，核范数是1/(2α)；L1范数在这个极限处并不按点态传递函数极限连续，慢尾段不能忽略。β=0仍须沿用V002单独退化分支。

标量系数锐性不证明后面的三个因子可同时达到乘积上界；没有据此称Bnew锐。

## 3. 双模态所有分支

复用V002已独立审过的结构：a=r1+r2，b=r1ω2+r2ω1，c=r1ω2²+r2ω1²，`c=(ω1+ω2)b−ω1ω2a`。若a≠0，设α=ζ0b/a、β=c/a，分子比为`N1/N0=1+2(κ−1)αRαβ`。

| 分支 | 新核引理或既有精确核给出的TV上界 |
|---|---|
| a≠0、β>0 | 系数结构使α>0；≤1+2(κ−1)=2κ−1 |
| a≠0、β<0、α≠0 | 稳定双边核范数1/sqrt(α²−β)，修正项≤2(κ−1)，故≤2κ−1 |
| a≠0、β<0、α=0，即b=0 | N1=N0，比为1；不写0乘潜在异常核 |
| c=0 | 共同原点零点消去，一阶核给≤κ≤2κ−1 |
| a=0 | 非平凡双模态必有b≠0；`κ−(κ−1)p/(s+p)`，p>0，TV恰为2κ−1 |
| 单有效留数 | 可消公共模态因子，原式因子上界仍成立 |
| H0恒零 | 仍须排除；不报告比值 |

所以分子因子的统一TV上界由4κ−3改善为2κ−1。

每个模态分母比写成

`Dj,0/Dj,1=1−2ζ1ωj(1−1/κ)R_(ζ1ωj,ωj²)`。

α=ζ1ωj>0、β=ωj²>0，新核引理给其有限测度TV≤3−2/κ。有限测度卷积的TV次乘性与V002的全时程恒等式y1=q*y0给Bnew。

这里保留ω1≠ω2>0、实留数非全零、0<ζ0≤ζ1、固定实位移/恢复力输出和输入分布、同一紧支撑实L1输入、零初始、包含完整自由尾段等原前提。κ=1时所有修正项为0、Bnew=1。非最小相位分子仍用稳定双边核；这个步骤不能把全时程sup替成同一截断窗内sup。

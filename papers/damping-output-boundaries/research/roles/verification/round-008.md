## 1. 输入符号和完整投影

采用相对物理坐标u，`M u''+C u'+K u=−M b a(t)`，置f=−a；完整实质量归一模态满足`ΦᵀMΦ=I`、`KΦ=MΦΛ`、`λi=ωi²>0`。Γi=φiᵀMb，固定实输出y=ℓᵀu，相对于f的留数定义为ρi=(ℓᵀφi)Γi；相对于a则整体为−ρi。

完整性使ΦΦᵀM=I，且A=M⁻¹K=ΦΛΦᵀM。因此对整数p，

`Σ λi^p ρi = ℓᵀΦΛ^pΦᵀMb = ℓᵀA^p b`。

p=−1要求K正定可逆、无刚体模态；特别地μ−1=ℓᵀK⁻¹Mb为单位静态f输出，μ0=ℓᵀb，μ1=ℓᵀM⁻¹Kb。经典阻尼是将这些ρ等同于解耦传递函数实留数的条件；矩恒等式本身是M/K完整投影，不靠阻尼拟合得到。

任意逐阶振型换号会同时翻转ℓᵀφi与Γi，所以ρi不变。不能通过逐阶任意改振型正负来修改物理留数符号。整体输入或输出换号只使所有ρ同乘一常数；后面的排除允许任意非零共同尺度，已包括这个自由度。

## 2. 整体弹性投影及局部矩表

取ℓ=Kb时，`ℓᵀφi=λiΓi`，所以ρi=λiΓi²≥0。对一般SPD M/K这是一项广义整体弹性输出；与软件“基底剪力”是否完全一致仍需核输出定义。它不包含C u'，也不等于耗能或绝对加速度。

对标准一维固定基剪切楼，M=diag(mj)>0、K=Bᵀdiag(kj)B、kj>0，b=1；B取层间差，u0=0。累计弹性层剪Sj=kj(uj−u(j−1))，净弹性层力Nj=Sj−S(j+1)=(Ku)j。Kb=k1e1，所以S1=1ᵀKu就是上述整体弹性投影。

三层时完整必要矩为：

| 输出 | μ−1 | μ0 | μ1 |
|---|---:|---:|---:|
| S1 | m1+m2+m3 | k1 | k1²/m1 |
| S2 | m2+m3 | 0 | −k1k2/m1 |
| S3 | m3 | 0 | 0 |
| N1 | m1 | k1 | k1(k1+k2)/m1 |
| N2 | m2 | 0 | −k1k2/m1 |
| N3=S3 | m3 | 0 | 0 |

μ−1列也可完全不经模态、由静态层平衡Sj−S(j+1)=mj从顶向底累加得到。顶层μ2=k1k2k3/(m1m2)>0；μ2是λ²=ω⁴矩，不是ω³矩。

独立核对源稿的附加符号式：由k1φ1i=λiΓi、第一行特征方程及逐层平衡，令wi=ρi(S1)=λiΓi²>0，则

`ρi(S2)=(1−λi m1/k1)wi`，

`ρi(N1)=(λi m1/k1)wi>0`，

`ρi(N2)=[λi m2/(k1k2)](k1+k2−λi m1)wi`。

标准连通剪切链中φ1i不能为0，否则第一行递推使整条振型为0。因此上面的wi严格正，按递增λ排列，S2/N2的非零留数至多一次符号变化；N1同号。该符号结论并不意味着幅值或时程峰值随阻尼单调下降。

## 3. 两个见证的尺度不变排除

C008给定完整三模态ω=(1,2,3)、ρ=c(1,−2,1)，c≠0：

`μ−1=11c/18, μ0=0, μ1=2c, μ2=50c`。

- S1/N1需要μ0≠0，排除。
- S3/N3需要μ1=0，排除。
- S2/N2需要μ−1>0、μ1<0，而候选两者同号；等价比值μ1/μ−1=36/11>0，与负值要求矛盾。任何共同尺度和整体换号均无效。

所以该给定完整三模态见证不可能成为标准三层模型的任一Sj/Nj。+−+或−+−也违反S2/N2一次符号变化条件，但顶层的排除仍用矩，不能仅看符号变化数。

E004给定ω=(1,3)、ρ=c(1,−89/10)：μ0=−79c/10、μ−1=c/90，比例μ0/μ−1=−711。非底层Sj/Nj需μ0=0；底层S1/N1的μ0与μ−1同号。因此这两个有效留数不能作为标准两层剪切楼的相应弹性输出。更一般，若增加的模态留数**确实全为0**，矩仍不变，排除同样有效；未知或额外非零剩余留数则是另一个完整模型，不能据此排除。

这些是必要条件，不是任意正m/k逆实现的充分条件。若完整λ和真实M/K/b/ℓ都已给定，有限个精确矩可能唯一确定留数；那也不同于证明存在某个正m/k模型。

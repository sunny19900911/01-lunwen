# 独立验证第5轮：归一化Lipschitz输入类上的有限比值存在性

2026-10-17 09:14 +08:00；V005。主控候选：固定T、L，实标量输入支撑于[0,T]、||u||∞=1、Lip(u)≤L，两个稳定SISO有理系统零初始，H0非恒零，取完整峰值。先审核定义再独立推导；不假定候选必真。

**结论：在“稳定”明确为proper且所有极点严格左半平面（BIBO稳定），并把Lip施加于输入的全实轴零延拓后，统一有限峰值比确实存在。** 这是紧性和注入性的存在性推论，常数依赖T、L及两个完整系统，不给工程可用数值，也不是仅依赖κ的统一定理。不主张新原理或文献首创。

## 1. 输入函数空间、非空与闭包

固定T>0和0<L<∞，令

`K_(T,L)={u∈C(R;R): suppu⊂[0,T], ||u||∞=1, |u(t)−u(s)|≤L|t−s| 对所有s,t}`。

等价地，在C([0,T])中要求端点u(0)=u(T)=0、sup范数1、Lipschitz常数≤L，然后作零延拓。必须说明全局零延拓；仅说“窗内Lipschitz”不会自动给端点连续。

该类非空当且仅当LT≥2：若|u(t*)|=1，则从两端0走到该峰值都至少需时1/L；反向可取中心为T/2、半宽1/L的三角形帽函数。LT=2允许唯一宽度的正/负帐篷等情形，无须额外要求严格大于2。T=0或L=0时该归一化类为空，不作为非空命题。

限制到[0,T]后，该集合统一有界且等度连续。Arzelà–Ascoli给相对紧性；端点条件、固定支撑、Lipschitz不等式及||u||∞=1都在一致收敛下封闭。特别地，范数1不会在极限中变为0。因此K_(T,L)在sup范数下紧，零延拓后仍为C0(R)中的紧集。

## 2. 输出映射与连续性

对实因果stable proper rational Hk，冲激响应为有限实符号测度

`μk=dk δ0 + hk(t)dt`，其中hk∈L1([0,∞))。

这包含strictly proper情形dk=0，也允许常数直通项；本命题不局限于位移输出。零初始输出算子Sk u=μk*u满足

`||Sk u−Sk v||∞ <= ||μk||TV ||u−v||∞`。

输入属于C0(R)，卷积输出也连续且在两端无穷远趋0（起始前为0，正无穷为衰减尾段），因此完整峰值Pk(u)=||Sk u||∞是良定义的有限值；它对u的sup范数连续。非最小相位或虚轴传递零点不影响这一步；只要求系统极点稳定。

如果“稳定有理”仅指极点条件而允许improper传递，原命题不一定良定义。例H0=1、H1=s²均无不稳定有限极点，但三角帽Lipschitz输入的第二导数含Dirac项，H1输出不是具有有限普通L∞峰值的函数。所以需要proper/BIBO条件，或改用更强输入空间另行推导。本轮不对improper情形作存在性断言。

## 3. 非零H0对这些输入的注入性

每个u∈K_(T,L)都属于L1∩L2且非零。stable proper rational H0在实频轴上有界，且非恒零意味着其虚轴零点最多是有限个点，因而H0(iω)非零几乎处处。

若S0u恒零，则由L2傅里叶变换/Parseval有`H0(iω)û(ω)=0`几乎处处；除去有限零点即得û=0几乎处处，故u=0于L2。再由u连续，推出u恒零，与sup范数1矛盾。因此

`P0(u)>0 对所有u∈K_(T,L)`。

这里不要求H0具有稳定因果逆，不要求最小相位，也不因有单个实频传递零点就失去对紧支撑L2输入的注入性。SISO条件重要：一般MIMO的“非零传递矩阵”并不等于无输入零空间。

## 4. 紧性给统一正下界

连续正函数P0在非空紧集K_(T,L)上取得最小值

`m_(T,L,H0)=min_(u∈K) P0(u)>0`。

若最小值为0，则极小点本身违背上一节注入性；也可用极小化序列的一致收敛子列证明。与此同时

`P1(u) <= ||μ1||TV ||u||∞ = ||μ1||TV`。

所以所有u∈K_(T,L)满足

`P1(u)/P0(u) <= ||μ1||TV / m_(T,L,H0) <∞`。

更直接地，连续比值P1/P0在该紧类上取得有限最大值；上述常数只是一个存在性的保守表达。H1可以恒零，此时最大比值为0。整个论证针对完整输出，包含自由衰减尾段；未把截断观察窗、非零初始状态或不同输入拼接进去。

## 5. 与前轮反例和齐次性的关系

V004的原高频输入范数为1，但Lipschitz常数随载频增大，离开本紧类。乘e^−ν后虽能满足绝对导数上限，sup范数同时趋0，不满足本轮范数1；再归一化又恢复高频变化率。这正是新命题与缩幅反例不冲突的原因。

等价的齐次输入条件可写为：非零输入固定支撑且`Lip(u) <= L||u||∞`，将u除以其sup范数即可回到K_(T,L)。只有绝对上限Lip(u)≤L并允许||u||∞→0，不能使用本轮正下界。

归一化和Lipschitz有限常数两者缺一都失去当前紧性证明。证明没有说明可删其中任一条件，未给这些条件的必要性分类。

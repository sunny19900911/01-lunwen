## V-DM-01：分母与退化情况的独立检查

设

`u = r_1 d_2 + r_2 d_1`，`v = r_1 b_2 + r_2 b_1`，故 `A=u^2, B=v^2`。

由两条线性关系 `u=v=0` 对留数的系数矩阵，其行列式为

`d_2 b_1 - d_1 b_2 = 2 Omega (omega_2-omega_1)(omega_1 omega_2+Omega^2)`。

上述前提使其非零，因此 `r != 0` 蕴含 `A+B x > 0` 对所有 `x>0` 成立。又 `E=b_1^2 b_2^2>0`，分母等于

`(d_1^2+x b_1^2)(d_2^2+x b_2^2)>0`。

所以式(8)两侧乘分母保持符号，式(10)不存在有限正阻尼奇点。

- `B=0`：必有 `A>0`，导数严格为负，无正峰值。
- `A=0`：必有 `B>0`。若 `C>0`，正峰值为 `sqrt(C/E)`；若 `C=0`，约去共同因子后仍严格递减，不适用反共振公式(13)。
- `C=0`：表示激励恰逢某固有频率；正阻尼保证原式有限，不是系统极点奇点。
- `Omega=0`、`zeta_0=0` 和重频不在原定理适用域；不能直接把式(10)延拓过去。

将差值分子重新整理为

`S = E(A+B x_0)(x_cross-x_1)`，

得到式(10)的区间叙述。式(11)的分子导数为 `-2 E(A+B x)`，在 `x>0` 严格负，因此若 `BC>AD`，正根存在且唯一；若 `BC<=AD`，没有正的放大导数区。该推导独立给出峰值分类，不依赖网格扫描。

式(12)接近 `BC=AD` 时有相减消去误差。计算实现宜用等价式

`x_peak = (BC-AD) / [ E (sqrt(A^2+(B/E)(BC-AD))+A) ]`，

只在 `B>0, BC>AD` 分支使用。原解析式未因此失效。

## V-DM-02：最小无激励输出反例

取 `M=I_2`、`K=diag(1,4)`、`C_zeta=2 zeta diag(1,2)`，固定标量输入分布 `g=(1,0)^T`、固定测量 `ell=(0,1)^T`，零初始。

此时质量、刚度正定，阻尼为正，固有频率不同，且测量向量确为非零；但 `Gamma=(1,0)` 导致 `r=(0,0)`，故任何阻尼下 `Y=0`。幅值比为 `0/0`，`x_cross=0/0`，严格递减叙述不成立。若把“非零输出”定义成非恒零传递输出，该例自动被排除。

建议准确前提：**至少一个有效模态留数非零（双模态且重频排除时，等价于传递函数不恒零）**。

## V-DM-03：同号并不等于单调减幅

同号定理的推导正确：整体变号后 `c_i>=0`，只要某一 `c_i>0`，即有 `-Im H>0`，可对 `log|H|` 求导并积分。证明不要求 `zeta<1`。

但该定理是比例界，不是单调性定理。例如 `omega=(1,2)`、`r=(1,2)`、`Omega^2=2` 时，两留数均正，却处于无阻尼反共振：

`(A,B,C,D,E)=(0,128,4,64,256)`。

`zeta: 0.05 -> 0.08` 时幅值比为 `1.5525114155251143 > 1`，且小于 `kappa=1.6`。这不是对定理1的反例，而是对“同号留数意味着幅值随阻尼单调下降”的有效最小反例。其来源是不同模态实部跨越共振后相反；留数正不等于所有模态复响应同向。

## V-DM-04：L2的严格性与常数可达性

双模态非零有效留数下，对每个 `Omega>0`，式(14)为严格上界。因为 `A+B x_0>0` 且 `D,E>0`，分母比严格小于1，而分子比至多 `x_1/x_0`。

对任何非零 `f in L2(R)`，零初始、全时程含尾段输出同样满足

`||Y_1||_2 < kappa ||Y_0||_2`。

理由：频域差 `kappa^2 |H_0|^2-|H_1|^2` 在正频率上严格正；非零L2输入的频谱不能只支撑在单点 `Omega=0` 或其他零测度集合。负频率由实系数共轭对称处理。Parseval积分因此严格正。若输入为零，只有非严格不等式；无限持续纯谐波不属于此L2前提。

严格上界并不意味着存在更小的统一常数。除了原稿的跨模型构造，固定 `omega=(1,2), r=(1,-1)` 已有更简单的锐性路径：

`H(Omega,zeta) = 1/(1-Omega^2+2i zeta Omega) - 1/(4-Omega^2+4i zeta Omega)`。

其分子为 `3+2i zeta Omega`、分母的主项为 `Omega^4`，故

`H(Omega,zeta) ~ 2i zeta / Omega^3`，`|H_1|/|H_0| -> kappa` 当 `Omega -> infinity`。

这里质量、刚度、留数和阻尼对都固定，只改变激励频率；绝对响应趋零。借助每个有限频率附近正测度窄带输入，还可使非零L2输出比任意逼近 `kappa`。这只证明理论常数锐性，不说明工程高频输入有足够能量或真实局部响应必放大。

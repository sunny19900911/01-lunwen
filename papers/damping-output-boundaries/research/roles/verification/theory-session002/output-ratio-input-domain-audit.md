# 输出比输入域澄清：反因果稳定重构与因果指数输入

## 结论与适用边界

**派工玩具的全部公式成立，未发现必修缺口。** 对紧支撑实 L1 输入，两个稳定因果零初始系统的完整峰比有有限界；允许持续指数增长的局部平方可积输入后，同一对系统可以有有限基准能量、无限新态能量。这里的关键不只在 L2 与 L∞ 的选择，而在输入域及相应卷积结合律的前提。具体指数输入下，稳定反因果重构与真实因果输出确实不同；绝对双重积分发散，不能交换次序。

本例是任意 a,b>0 的非结构标量 LTI 玩具，不是阻尼物理模型、三层真实 topcut 反例或新核心贡献。它仅说明两种数学命题能够相容；不能据此断言 Teixeira 原文实际允许该输入，或宣布其定理与 C018 的全部差别已核清。该文定义、截断方式、零初始及其他可容许条件仍由文献角色直接核原文。本次不搜索或代补 source 结论。

## 1. 核、传递函数及零初始

以下信号在负时间延拓为零，令 c=a+b>0。两个因果严格真、稳定传递函数及普通核为

\[
H_0(s)=\frac{s-a}{(s+b)^2},\quad
H_1(s)=\frac1{s+b},\qquad
h_0(t)=(1-ct)e^{-bt}\mathbf1_{t\ge0},\quad
h_1(t)=e^{-bt}\mathbf1_{t\ge0}.
\tag{T1}
\]

两核均在 L1∩L2∩L∞，极点均为 −b；H0 的 a>0 是传递零点，不是机械或系统极点。定义因果零初始输出为 yj=hj*f，不引入任何非零初始状态。商为

\[
Q(s)=\frac{H_1}{H_0}=\frac{s+b}{s-a}
=1+\frac c{s-a},\quad
q=\delta_0-c e^{at}\mathbf1_{t<0}\,dt,\quad
\|q\|_{TV}=1+\frac ca=2+\frac ba.
\tag{T2}
\]

q 是稳定双边有限测度，普通部分反因果；其双边 Laplace 收敛域为 Re s<a。在该域中普通部分变换为 −c/(a−s)=c/(s−a)。这不同于 Q 的因果逆核 δ0+c e^{at}1(t≥0)dt，后者不稳定。

## 2. q*h0=h1 与紧支撑输入的完整峰界

直接设

\[
I(t)=\int_0^\infty e^{-au}h_0(t+u)\,du.
\]

当 t<0，换元 v=t+u 给 I(t)=e^{at}H0(a)=0；当 t≥0，积分给 I(t)=−t e^{-bt}。因此

\[
(q*h_0)(t)=h_0(t)-cI(t)=h_1(t)
\quad(t\in\mathbb R).
\tag{T3}
\]

对任意实 f∈L1（特别是紧支撑实 L1），相关绝对双重积分逐点有界：

\[
\int_{\mathbb R}d|q|(r)\int_{\mathbb R}
|h_0(v)|\,|f(t-r-v)|\,dv
\le\|q\|_{TV}\|h_0\|_\infty\|f\|_1<\infty.
\tag{T4}
\]

故 Fubini/结合律合法，y1=(q*h0)*f=q*(h0*f)=q*y0，原因果系统的完整输出保持，包括全部自由尾段。若 f 为非零因果输入，H0(iω) 在实频上不为零，Fourier 唯一性给 P0>0。令 Pj 为 t≥0 完整输出峰，负时间原输出为零，则

\[
P_1\le\left(2+\frac ba\right)P_0.
\tag{T5}
\]

常数是 TV 上界，未称输出像空间上的最优常数等于 TV。反因果 q 使用未来基准输出，所以不能把完整峰换成同一截断观察窗。此例中紧支撑甚至可放宽为原全 L1 输入。

此外，f∈L1 时 hj∈L2 给 yj∈L2，且同一恒等式和测度 Young 界给 ||y1||2≤(2+b/a)||y0||2。因此在这个输入类里改用完整 L2 能量，也不会得到未消 RHP 零点必然失界的结论；不能只用“一个是 L2、一个是 L∞”解释。

## 3. 非紧支撑指数输入的真实因果响应

取

\[
f(t)=e^{at}\mathbf1_{t\ge0}.
\tag{T6}
\]

它在每个有限时间窗平方可积，按通常局部平方可积定义属于 L2e；但它不在 L1 或 L2，也不紧支撑。此处仅核该通常定义，未替 Teixeira 原文核全部 admissibility 条件。

因果卷积在每个有限 t 均存在。也可在 Re s>a 的共同因果 Laplace 收敛域计算 F(s)=1/(s−a)，得到

\[
y_0(t)=t e^{-bt}\mathbf1_{t\ge0},\qquad
y_1(t)=\frac{e^{at}-e^{-bt}}c\mathbf1_{t\ge0}.
\tag{T7}
\]

两输出 t=0 均为零；这是两原稳定因果系统的零初始响应，不依赖预置零动态状态。H0F 中的零点消去使 y0 衰减，但不把 f 变成可积输入。

\[
\|y_0\|_2^2=\frac1{4b^3}<\infty,\quad
\|y_1\|_2=\infty,\qquad
P_0=\frac1{be}<\infty,\quad P_1=\infty.
\tag{T8}
\]

所以同一指数输入连完整峰值比较也失界。所需现象不依赖把能量范数换成峰值范数。

## 4. 结合律为何失败：两种分组存在但结果不同

对 T7 的有界 y0，q*y0 本身仍绝对收敛，逐点为

\[
(q*y_0)(t)=
-\frac1c\begin{cases}e^{at},&t<0,\\e^{-bt},&t\ge0.\end{cases}
\tag{T9}
\]

它并不等于真实 y1；全实轴上 y1−q*y0=e^{at}/c。稳定反因果重构使用另一种全时间边界选择，不能在这条增长输入上替代因果零初始映射。

具体失败发生在含反因果普通核的绝对双重积分。对任意固定实 t，Tonelli 给

\[
\begin{aligned}
D(t)&=c\int_{r<0}\int_{v\ge0}
e^{ar}|h_0(v)|e^{a(t-r-v)}
\mathbf1_{r\le t-v}\,dv\,dr\\
&=c e^{at}\int_0^\infty |h_0(v)|e^{-av}
\left[\int_{-\infty}^{\min(0,t-v)}dr\right]dv
=\infty.
\end{aligned}
\tag{T10}
\]

例如在 0<v<1/(2c) 上 h0(v)>0，内层 r 积分已经无限；反因果衰减 e^{ar} 被未来输入的 e^{-ar} 精确抵消。δ 项不能修复普通部分的绝对发散。

于是 q*(h0*f) 和 (q*h0)*f 各自的分组卷积虽存在，也不能交换二重积分或引用 T4。前者是 T9，后者是 h1*f=T7。仅说“f 不在 L1，所以无法证明”还不够；T9–T10 明确给出恒等式确实失败及 Fubini 前提失败的位置。

等价的变换提醒是：q 要求 Re s<a，而 f 要求 Re s>a，二者没有共同双边 Laplace 收敛域。不能只操纵有理式 QH0=H1，忽略其时域实现与收敛域。这也不否定 T3；核恒等式本身仍正确。

# C020输入空间补充：由C¹子类到原紧支撑实L¹类

2026-10-17 12:33 +08:00；纯解析短补充，状态candidate，交主控核准后供作者v003采用。不重推留数或常数，不新增数值，不改旧证据。

## 可直接采用的命题与证明

固定C020中的一个正三层物理topcut模型及κ>1，令`r=ζ₀/ζ*`、`δ=|r−1|`，并保留`0<δ≤ηκ=min{1/2,(κ−1)/(2κ)}`。分别记实紧支撑L¹输入类和其全轴零延拓为C¹的紧支撑子类为`F₁`、`F_C¹`，排除零输入；两状态均为零初始，峰值包含全部尾段。记对应最优峰比为`K₁`和`K_C¹`。则同一显式常数给出

\[
\frac{L_\kappa}{\delta}
\le K_{C^1}
\le K_1
\le \|q\|_{\mathrm{TV}}
\le \frac{U_\kappa}{\delta}.
\]

证明如下。两状态的稳定严格真有理传递函数具有`h_j∈L¹(R)∩C₀(R)`，故任意`f∈F₁`的输出`y_j=h_j*f`均连续、有界且属于L¹，特别

\[
P_j(f)\le\|h_j\|_\infty\|f\|_1<\infty.
\]

此处不要求原L¹输入本身有界。C020已构造同一商`Q=H₁/H₀`的稳定双边有限测度核q，并证明`||q||TV≤Uκ/δ`。由傅里叶唯一性有`q*h₀=h₁`；有限测度与L¹卷积的结合律/Fubini给

\[
y_1=q*y_0,\qquad P_1(f)\le\|q\|_{\mathrm{TV}}P_0(f),\qquad f\in F_1.
\]

因此原L¹类也受同一上界控制。基准H₀为非恒零有理函数，在实频轴上非零几乎处处。若非零L¹输入有P₀=0，则傅里叶乘积关系迫使其傅里叶变换几乎处处为0，再由唯一性得f=0，矛盾。因此所有比值的分母合法。

另一方面，C020下界所用的同一实sin²慢包络全轴零延拓为C¹、每次支撑有限且幅值≤1，故属于`F_C¹⊂F₁`。对每个固定模型/r，先选择这个共同输入，再令包络时长T趋大，既有全时刻误差估计给`K_C¹≥|Q(iS)|≥Lκ/δ`。由子类包含性即得上列完整链，原L¹类的最优K₁也有相同的κ-only双侧倒数阶。无需声称`K_C¹=K₁`，更未声称任何K等于TV(q)。

## 平移、振幅与量词

任意紧支撑L¹输入可作一次时间平移，使其支撑位于[0,∞)；时间不变系统的两个完整输出同时平移，峰值比不变，故与论文零初始半轴表述相容。若将C_c¹([0,∞))解释为支撑必须离开端点0，只需把慢包络再共同延迟一个正时间，结论不变。

慢包络下界已经满足|f|≤1。若C¹类另要求幅≤1，任意非零C¹紧支撑输入也可用正标量共同缩放达到此上限而不改峰比；但本证明不需要把所有L¹输入强加L∞归一化。T允许依赖模型和r，未给统一最大输入时长或同一截断观察窗界。

本补充只处理输入类桥接；常数仍由已审核C020给出，既未用同频下界偷换上界，也未引入密度论证来额外宣称两个最优常数数值相等。

# R009：线性 Maxwell 到辅助二阶系统的代数映射审查

开始读钟：2026-10-17 23:49:47 Asia/Shanghai。只写本文件；不 query、不读角色1未冻结文件、不实验、不审 R014、不判峰值闭式正确性。

## 先冻结本次 task 的文字条件

本次仅以主控任务消息为输入，冻结如下：

- α=1；固定 k,c>0，Maxwell 本构 F′=k(v−F/c)，v=δ̇ 为总变形速度。
- 定义 x=δ−F/k；拟核 ẋ=F/c、ẍ=(k/c)(v−ẋ)。
- 额外端点：δ(T)=δ(0)，F(0)=F(T)=0；将 δ(0)平移到0后，应有 x(0)=x(T)=0、ẋ(0)=ẋ(T)=0。
- 记 M=max|F|、|v|≤V；拟核 max|ẋ|=M/c。令 γ=k/c、u=γv，必须区分 u 的加速度量纲与真实器件力。
- 该映射是含线性阻力的辅助二阶系统，不是无阻力双积分器，不能引入真实器件质量解释。
- 同零位移端点而未给非平凡目标时有零轨迹；经典非零位移 rest-to-rest 最短时公式不得直接作为同一闭式。
- 任务中 Mmax=cV tanh(kT/(4c)) 仅为 candidate；本轮不审核其正确性。

以下审查在冻结这些条件后进行，不从其他角色文件补充隐含前提。

## 审查结论

**上述映射、端点转换和峰值换算在冻结条件下代数一致。** 它保留了一阶线性阻力项；不是无阻力双积分器的 rest-to-rest 问题。这个结论只核映射，不给候选 Mmax 闭式或其最优性背书。

### 1. 本构与坐标

对 x=δ−F/k 取导，并代入已冻结本构：

    xdot = v − Fdot/k = v − (v−F/c) = F/c;
    xddot = Fdot/c = (k/c)(v−xdot).

x 是串联弹簧变形 F/k 扣除后的**黏壶变形**；δ 是整个串联器件的总变形。xdot 是内部黏壶速度，v 是总速度，两者一般不同。若 v 仅为有界可测函数、δ和F为相应绝对连续解，上述导数等式按几乎处处理解；xdot=F/c 有连续代表，可据此解释端点速度及峰值。

### 2. 端点与峰值

由 F(0)=F(T)=0 得 x(0)=δ(0)、x(T)=δ(T)，并得 xdot(0)=xdot(T)=0。再用额外条件 δ(T)=δ(0)，平移定义 x̃=x−δ(0)，就有 x̃(0)=x̃(T)=0。平移不改变导数或速度峰值。

c>0 时，F=c xdot 直接给 max|xdot|=M/c。这一关系是力峰到内部速度峰的换算；**不能把总速度约束 |v|≤V 改写成原问题只剩 |xdot|≤V**，也不能因此将两种速度当成同一输入。

### 3. 辅助系统及量纲

令 γ=k/c、u=γv，得到

    xddot + γ xdot = u,       |u| ≤ γV.

| 量 | 身份 | 量纲 |
|---|---|---|
| x、δ、F/k | 黏壶变形、总变形、弹簧变形 | 长度 |
| xdot、v | 内部黏壶速度、总速度 | 长度/时间 |
| γ=k/c | 线性速度衰减系数 | 1/时间 |
| u=γv | 辅助方程输入 | 长度/时间² |
| F | 真实器件轴向力 | 力 |

辅助式中的单位二阶导数系数是变量归一化后的代数形式。本构未给出真实器件惯性质量，不能将 u 直接命名为真实控制力，或把该式解释为给器件加上某个物理质量。γ>0 时阻力项 γ xdot 不消失；若引用无阻力双积分器 xddot=u 的公式，就是更换动力学假设。

### 4. 零位移端点与非平凡目标

对零初末位置、零初末内部速度，仅有这些可行性条件时，x≡0、F≡0、v≡0 是平凡可行轨迹。因此经典“给定非零位移、从静止到静止”的最短时间公式与本任务的端点/目标不相同，不能把非零位移参数机械代成0，再宣称得到候选峰界。

若另外要求精确非零峰 M、给定耗散，或在固定 T 内最大化峰值，问题才带有相应非平凡目标；**零轨迹的可行性不说明它在峰值最大化问题中最优，也不说明最大峰为0。** 本轮只指出问题身份差异，不进行最优控制求解或取等构造。

# R022｜Correia 非线性 Maxwell 位移相关反升近邻：独立原页核验

本轮结论：**应纠正“已有近邻只涉及加速度／剪力反升”的宽泛表述。** Correia 的作者扩展论文在 α=0.15、串联弹簧与黏滞元件组成的 Maxwell 装置语境中，报告了位移／漂移相关指标反升。独立复算表8与上方表9的印刷数值，C=0→125 时分别增加 **4.1171289523%** 与 **16.9604788455%**。这足以排除把“被动装置下位移相关指标可能反升”作为首次现象发现。

但该文的响应定义、单位及比较条件尚不足以闭合 C027 或 C025 的全部条件。不能将印刷数值直接当作米制固定物理节点全时域峰值，也不能借“完全相同条件尚未检出”制造首次性主张。

## 2. Maxwell 语境与 K=0 的含义

PDF7 的 Damping 段落将 α 固定为0.15，C 从0（without damper）取至2500。这里 C 是装置黏滞参数，不能与研究模型背景阻尼矩阵 C 混同。图17及 Δ=ΔK+Δd 的分解明确呈现弹簧与黏滞元件串联。表5–7给出正且有限的串联刚度，例如1,000,000与3,000,000 kN/m。

PDF7 §3.4 在表8之前另说明：刚度100000、350000、700000的额外支杆安装在耗能装置**并联**位置。因此表8／9的 K=0 是没有这根额外并联支杆，**不是 Maxwell 串联弹簧刚度为零**。表8／9究竟沿用哪个串联刚度，当前原页没有闭合。

表5–7的 displ. max U1 属于装置变形语境，不能拿来当固定楼层响应的证据。PDF3的物理与几何非线性、分布塑性及 PDF5 的砌体语境，也使该研究不能直接等同于 C027 的固定线性 M/K/C 主体。

## 4. 表13归一化交叉核验与定义疑点

PDF9表13给出 h1=5.7 m、htop=29.7 m，高度差为24 m。Acc1 行给出 d1=0.038182、dtop=0.044036：

| 算术对照 | 独立计算 | 被对照印刷数 | 差值（印刷数减计算值） |
|---|---:|---:|---:|
| d1/5.7 | 0.00669859649122807 | 表8 C=0：0.0066986 | 1/285000000 |
| (dtop−d1)/24 | 0.0002439166666667 | 上方表9 C=0：0.00024392 | 1/300000000 |

两组吻合达到所列小数的舍入量级，强烈提示表8的基准数属于高度归一化的首层漂移比，不能因为图19轴标 m 就直接赋予原始数值米制单位。若同一正高度归一化适用于 C=125，反升比值保持不变；但原页未给出其对应 d1 原始数值，不能宣称已经闭合全列定义。

进一步按表13的六行计算 `(dtop−d1)/24`：Acc1为0.0002439166666667，Acc2为0.0002597916666667，Acc3为0.0002582083333333，Acc8为0.0002462083333333，Average为0.0002605，Acc2x为0.0003289166666667。它们与表列 Interstorey Drift 的差均不超过0.5×10⁻⁶；Average 恰在该显示半单位边界，不能据此断言某一种程序舍入规则。

**算术吻合不能证明同步峰定义。** 原文尚未明确这些位置量是 `max_t|u_top(t)−u_1(t)|`，还是分别取峰后的标量差等处理。不能把跨区平均漂移直接当作相邻层同步漂移峰，更不能当作固定节点绝对位移峰。

额外一致性限制：表13 Acc2x 的 d1/5.7≈0.01625719，与表10 a=2x、C=0 的0.01523193不同；跨区计算约0.00032891667，也与表11对应0.00036354不同。当前不能自动合并这两组2x基准，更不据此判原研究无效。本轮主要反升判定采用 a=1x 同表比较。

## 5. 与 C027、C025 的条件对照

| 事项 | Correia 本轮证据 | 对当前贡献边界的影响 |
|---|---|---|
| 非线性 Maxwell、位移相关反升 | α=0.15；图17串联模型；表8／上方9反升 | 已构成实质近邻，通用现象不能称首次 |
| 固定物理输出及单位 | 首层归一化疑点；top−1为跨区量；同步峰定义未闭合 | 不能直接视为 C027 固定 u1 的同一定义 |
| 主体模型 | 文中含物理／几何非线性、分布塑性等 | 不是 C027 的已明确固定线性 M/K/C 主体 |
| 装置与配对条件 | 装置类别及参数扫描明确；安装数量、表8／9串联刚度、背景阻尼、完整输入文件与初值未闭合 | “同a=1x组”有支持；严格同输入、零初值、单支路不能据此补写 |
| 时间域与证明层级 | 有30 s相关设置和有限计算表列；没有本轮可核验的连续全尾部界 | 不等于 C027 的连续控制组单点下界与无装置全时域上界证书 |
| C025 能量等同对象 | 无装置／有装置参数扫描；未证明端口交换下相同能量及装置历程 | 不能替代 C025 两布局严格等同历程、固定 u1 峰分离的命题 |

C027 的实际窄对象是：M=I、K=[[2,−1],[−1,2]]、C=0.1√K；单 Maxwell 支路 κ=8、c=10、α=0.3、B=e2；共同已知输入与全零初始条件；固定物理 u1；无装置全时域峰上界与有装置一个真实时刻响应下界分离。Correia 不是上述全部条件已经核实的重复证据。这个差异只限定当前证书的对象，**不证明其首次性**。

C025 的对象更强且不同：相同主体、输入与装置移到两个端口，所列总能量、输入功、装置力、总变形与总速度历程严格相同，但固定物理 u1 的全时域峰分离。Correia 的无／有装置扫描没有建立这些等同历程，也没有建立端口交换配对。非零不对称扰动扩展不能沿用这些严格等同承诺。对称、投影与能量分析工具本身仍属已有方法，不能包装成新理论。

## 1. 坐标、输入符号与完整模态恒等式

用u表示物理相对位移，用q表示质量归一模态坐标，避免把二者混为一组坐标：

`M u''+Cζ u'+K u=−M b a(t)`，`u=Φq`，

`ΦᵀMΦ=I, KΦ=MΦΛ, Λ=diag(λi), λi=ωi²>0`。

M/K固定正定、实完整模态、经典阻尼使模态解耦；若采用共同模态ζ路径，则 `q_i''+2ζω_iq_i'+λ_iq_i=−Γ_i a`，`Γ_i=φ_iᵀMb`。固定**物理弹性/位移输出** `y=ℓᵀu`。

为清楚处理符号，先取标量输入f=−a，定义

\[
\rho_i=(\ell^T\phi_i)\Gamma_i,\qquad
H_f(s)=\sum_i\frac{\rho_i}{s^2+2\zeta\omega_i s+\lambda_i}.
\]

相对于实际a的留数为r_i=−ρ_i。后文允许共同非零尺度c，故整体输入/输出换号不会改变排除结论。

完整性给 `ΦΦᵀ=M^-1`。令A=M^-1K，则对整数p（A可逆），

\[
\boxed{\mu_p:=\sum_i\lambda_i^p\rho_i=\ell^TA^pb.}\tag{P1}
\]

特别地，

`μ0=Σρ=ℓᵀb`，

`μ1=Σω²ρ=ℓᵀM^-1Kb`，

`μ−1=Σρ/ω²=ℓᵀK^-1Mb`。

μ−1就是单位静态f的输出。该等式要求完整模态，或另有明确截断剩余项；累计质量参与比例接近1不保证带ω²权重的矩误差小，不能用截断局部拟合系数强制认证完整矩。

## 2. 整体弹性基底力：同号但不单调

取ℓ=Kb，输出为 `Fel=bᵀKu`。利用K对称，

`ℓᵀφi=bᵀKφi=λi bᵀMφi=λiΓi`，

故

\[
\boxed{\rho_i^{F_{el}}=\lambda_i\Gamma_i^2\ge0.}\tag{P2}
\]

实际a传递留数全非正。这个一般SPD结论不依赖三层模型。某模态未被输入激励时Γi=0，允许零留数。

在标准正质量、正层刚度剪切链且b=1时，Kb=k1e1。特征方程给k1φ1i=λiΓi；若φ1i=0，第一行递推迫使所有分量为0，不是特征向量，所以每个Γi非零，(P2)在完整链上严格正。

同号仅允许调用已证明的相应幅值/L2界及其前提，**不提供阻尼增大后每一谐波或每条时程峰值都下降的结论**。整体弹性Fel也不能直接代替含阻尼力的总平衡力。

## 3. 三层剪切楼的累计截面和净弹性层力

设M=diag(m1,m2,m3)，所有mj>0，

\[
K=\begin{pmatrix}k_1+k_2&-k_2&0\\-k_2&k_2+k_3&-k_3\\0&-k_3&k_3\end{pmatrix},
\quad k_j>0,\quad b=(1,1,1)^T.
\]

累计弹性层剪定义为 `Sj=kj(uj−u(j−1))`，u0=0；S4=0。净弹性层力 `Nj=Sj−S(j+1)=(Ku)j`，输出向量分别为

`ℓS1=k1e1, ℓS2=k2(e2−e1), ℓS3=k3(e3−e2)`；

`ℓNj=Kej`。

因为Kb=k1e1，(P1)立即给必要矩表（均针对自然正向f=−a）：

| 输出 | μ−1=Σρ/λ | μ0=Σρ | μ1=Σλρ |
|---|---:|---:|---:|
| S1=整体弹性基底剪力 | m1+m2+m3 | k1 | k1²/m1 |
| S2 | m2+m3 | 0 | −k1k2/m1 |
| S3 | m3 | 0 | 0 |
| N1=S1−S2 | m1 | k1 | k1(k1+k2)/m1 |
| N2=S2−S3 | m2 | 0 | −k1k2/m1 |
| N3=S3 | m3 | 0 | 0 |

静态逆矩一列来自静态力平衡：层剪为该层及以上质量和，净层力为本层质量。顶层另有

`μ2(S3)=μ2(N3)=k1k2k3/(m1m2)>0`。

这里μ2是ω⁴矩，不把它写成ω³矩。普通经典阻尼高频展开还含Σωρ等奇数频率矩，不能只凭上述偶数矩消项就宣称某个相对阶；Cζ一般不是局部剪切阻尼拓扑。

### 附加符号检查

令wi=ρi(S1)=λiΓi²>0，第一行特征方程及相邻截面关系给

`ρi(S2)=[1−λi m1/k1] wi`，

`ρi(N1)=(λi m1/k1) wi>0`，

`ρi(N2)=[λi m2/(k1k2)](k1+k2−λi m1) wi`。

按递增λ排列，S2/N2至多一次非零符号变化；S3可出现两次变化。该符号约束也不是时间峰值单调性。

## 4. 排除c(1,−2,1)及E004的截面归属

对ω=(1,2,3)、ρ=c(1,−2,1)，c≠0，精确有

`(μ−1,μ0,μ1,μ2)=(11c/18,0,2c,50c)`。

- S1/N1要求μ0=k1≠0，直接排除。
- S3/N3要求μ1=0，直接排除。
- S2/N2要求μ−1>0、μ1<0，而候选两者同号；任何共同正缩放或整体变号都不能使其乘积由正变负，故排除。

S2/N2的至多一次符号变化也排除了候选的+−+及−+−。因此无需未知m/k拟合或大范围逆谱搜索，就能排除**这组完整留数作为指定标准剪切楼的任何层剪或净弹性层力**。

对E-EXP-004，ω=(1,3)、ρ=c(1,−89/10)，有

`μ0=−79c/10, μ−1=c/90`。

非底层Sj和Nj要求μ0=0，候选不满足；底层S1/N1要求μ0和μ−1同号，候选乘积为负，亦不满足。因此E004的**仅这两个有效留数**不能作为该类剪切楼的这些输出，即使允许增加其他零留数模态，矩条件也不会改变。加入额外非零留数会成为新模型，须重查完整矩。

这些必要矩通常不是自由正m/k逆实现的充分条件。若实际M/K/b/ℓ已经给定且完整互异λ已知，匹配p=0,1,2三个精确矩可唯一确定三个留数（Vandermonde可逆）；这与“存在某组正m/k”是不同的问题。

## 6. 净弹性力、含阻尼总量与绝对加速度

在本剪切模型、b=1时，逐层动力平衡为

`(Ku)j+(Cζu')j=−mj(u_j''+a)`。

因此Nj=(Ku)j只是**净弹性结构力**。右侧是有符号的负惯性项，必须另计阻尼行力，不能直接称Nj为完整惯性力。累计相应总量可写为 `Sj+Σ(q≥j)(Cζu')q=−Σ(q≥j)mq(u_q''+a)`；是否等于软件输出，仍须核输出定义。

含阻尼总量的输出含速度及随ζ改变的Cζ，不能默认固定实留数式的同一ℓ。固定节点绝对加速度是u''+ba，保留直接输入项及ζ相关分子；楼层空间Max/Min还会改变控制点，更不能当一个固定线性输出。

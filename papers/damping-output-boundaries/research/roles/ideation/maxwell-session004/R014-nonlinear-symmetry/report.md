## 裁决与证明范围

冻结α=3/10系统有唯一全局解，且两布局满足对全部t≥0的精确关系u_B=P u_A、v_B=P v_A、F_B=F_A；总端口变形δ_B=δ_A，指定全局能量、耗散和输入功历史相同。对任意停载后时刻s≥T，若有真实状态能量的认证上包络E(s)≤Ebar(s)，则

\[
\sup_{t\ge s}|u_1(t)|\le
\sqrt{2\overline E(s)\frac{1001}{1002}}.
\]

**本轮没有建立α=0.3两布局的全尾峰值分离。** 线性核与旧线性阈值不在本证明中。有限步长RK4的峰差及末能量只能作为数值诊断；要把其末能量用于严格尾证书，须补真实状态误差及舍入的认证证据。本结果使用经典唯一性、机械储能与二次型不等式，不主张新经典方法或实际工程效果。

## 1. 固定方程、参数和正则性

沿用冻结协议的无量纲M=I₂，ε=1/1000，K=I+ε[[1,−1],[−1,1]]，w=√(1+2ε)，

\[
C=\frac{0.1w}{1+w}I+\frac{0.1}{1+w}K=0.1\sqrt K.
\]

K的特征值为1,w²，C的特征值为0.1,0.1w，故K,C均正定，裸主体的两阶模态阻尼比各为0.05。两质量各自接固定参考端，并由正弹簧连接；器件的B_A=(1,0)、B_B=(0,1)也各通到同一个固定参考端。不是通常仅底层接地的剪切链。

令r为(1.7,1.73)中r³−3r+0.1=0的唯一根，κ=3r²−1−0.1r³>7，c=κ/r³>0。r在此只生成冻结无量纲参数。α=3/10，q=1/α=10/3，

\[
\psi(F)=\operatorname{sgn}(F)(|F|/c)^q
=c^{-q}|F|^{q-1}F,
\]
\[
\dot u=v,\quad M\dot v=b g-Cv-Ku-B^TF,
\quad \dot F=\kappa(Bv-\psi(F)),
\]

其中b=(1,1)ᵀ、g(t)=sin(t)1_[0,T]、T=20π，u(0)=v(0)=F(0)=0。

ψ为C¹函数：F≠0处ψ'=q c^{-q}|F|^{q−1}，零点导数为0且连续。因此向量场对状态局部Lipschitz，冻结连续、有限支撑输入下有唯一局部解。q>1不使向量场全局Lipschitz；全局延拓须另靠下一节的能量估计。这里用的是串联器件的反演黏壶速度ψ(F)，不能把总端口速度Bv直接代入裸黏壶力式。

数值c只在本α=0.3的A/B内部代表相同资源；更换幂指数时保持同一数字，不代表同一有量纲器件或同一物理c。本例不校准实际500000/477，也不赋予实际单位或工程预测身份。

## 2. 机械能量、被动性及全局存在

定义完整储能

\[
E(u,v,F)=\frac12v^TMv+\frac12u^TKu+\frac{F^2}{2\kappa}.
\]

对局部解逐项微分，结构端口项−F Bv与器件弹性储能项+F Bv抵消，得到

\[
\dot E=v^T b g-v^TCv-F\psi(F)
=v^T b g-v^TCv-\frac{|F|^{13/3}}{c^{10/3}}.
\]

储能控制全部u,v,F；背景耗散对v正定，器件耗散对非零F为正。瞬时v=F=0但u≠0时E'可为零，故不把E'误说成对完整状态严格负定。

因C正定，完成平方给

\[
\dot E\le\frac14g(t)^2 b^TC^{-1}b.
\]

本协议Cb=0.1b，故bᵀC⁻¹b=20。对任意t≥0，

\[
0\le E(t)\le5\int_0^{\min(t,T)}\sin^2\tau\,d\tau
\le50\pi.
\]

最后一步使用T=20π及零初态。该先验界使解在所有有限时间保持有界，结合局部Lipschitz延拓定理排除有限时间爆破，得到唯一全局解。它也给出一个纯解析但粗的认证能量上界50π；不能用这个共同粗界推出局部峰排序。

停载后t≥T，E'=−vᵀCv−|F|^{13/3}/c^{10/3}≤0。停止输入既不等于终力回零，也不等于器件弹性储能消失；任何有限末时的F²/(2κ)均须保留。单凭能量不增不能断言|u1|逐点不增，亦不能凭有限末时的小浮点残值假定尾段已结束。

## 3. 非线性交换与完整历史等同

令P交换两坐标。PM=MP，PK=KP，PC=CP，Pb=b，B_B P=B_A。将A解变为(Pu_A,Pv_A,F_A)：结构项由P共轭，器件端口满足B_B Pv_A=B_A v_A，ψ(F_A)完全相同。因此该变换满足B布局方程及同一初态，由全局唯一性，全部t≥0均有

\[
u_B=Pu_A,\quad v_B=Pv_A,\quad F_B=F_A.
\]

取固定参考端口总变形δ=B u及端口速度δdot=Bv，得到δ_B=δ_A、δdot_B=δdot_A。还可分开弹簧和黏壶变形：δ_s=F/κ、δ_d=δ−F/κ，后者满足δdot_d=ψ(F)。两布局的这两个分量历史也相同。这里结构物理u1与器件总变形δ是不同输出，不能同名混用。

以下历史逐时相同，积分后任意相同窗口的对应量也相同：

| 量 | 定义 |
| --- | --- |
| 总动能 | vᵀMv/2 |
| 主体弹性能 | uᵀKu/2 |
| 器件弹簧能 | F²/(2κ) |
| 背景耗散功率 | vᵀCv |
| 器件真实耗散功率 | abs(F)^(13/3)/c^(10/3) |
| 输入功率 | g bᵀv |
| 器件端口功率 | F δdot |

据此，以这些量按同一公式、同一窗口计算的能量等效阻尼指标在分母非零处相同。端口功与真实耗散仍有弹簧端点项，不能无条件等同二者。交换关系并未给出同一个固定u1的相等或严格不等峰值；它仅给u1,B=u2,A。交换不变的全楼最大坐标指标相同。

## 4. 停载后的条件尾证书

给定任意s≥T及经认证的非负上包络E(s)≤Ebar(s)。停载后无其他外部做功，故所有t≥s有E(t)≤Ebar(s)。由K正定及Cauchy–Schwarz不等式，

\[
|\ell^Tu(t)|^2\le(\ell^TK^{-1}\ell)(u^TKu)
\le2\overline E(s)\ell^TK^{-1}\ell.
\]

因此固定ℓ=e1的全部未来绝对位移受报告首式控制，因

\[
K^{-1}=\frac1{1+2\epsilon}
\begin{pmatrix}1+\epsilon&\epsilon\\\epsilon&1+\epsilon\end{pmatrix},
\quad e_1^TK^{-1}e_1=\frac{1001}{1002}.
\]

同一上包络还给全部t≥s的器件力界|F(t)|≤√(2κEbar(s))、总端口变形界|B u(t)|≤√(2Ebar(s) B K⁻¹Bᵀ)。两布局的B K⁻¹Bᵀ也等于1001/1002。以上是经典储能转换的条件界，不是实际尾峰值等式。

纯解析50π可作为粗Ebar(s)。若希望采用远小于该值的RK4末能量，必须先通过下一节的误差认证门；不能将未经认证的浮点Ehat(s)直接代入Ebar(s)。

## 5. 数值末能量成为认证上包络所需的门

记状态z=(u,v,F)，H=diag(K,M,1/κ)，E(z)=zᵀHz/2。若在s有认证状态误差e=z−zhat，以及

\[
\overline E_{err}\ge\frac12e_u^TKe_u+
\frac12e_v^TMe_v+\frac{e_F^2}{2\kappa},\qquad
\widehat E_{upper}\ge E(\widehat z),
\]

则能量范数三角不等式给出安全选择

\[
\overline E(s)=
\left(\sqrt{\widehat E_{upper}}+\sqrt{\overline E_{err}}\right)^2.
\]

Eerr是**状态误差自身的二次储能**，不是未控制符号的“能量差”。例如认证的Euclidean误差界∥e_u∥₂≤η_u、∥e_v∥₂≤η_v、|e_F|≤η_F可给

\[
\overline E_{err}=\tfrac12\lambda_{max}(K)\eta_u^2+
\tfrac12\lambda_{max}(M)\eta_v^2+\eta_F^2/(2\kappa).
\]

参数表示、特征值、代数运算和舍入同样须由上包络覆盖。误差可来自适用本局部非线性系统的验证ODE积分、带认证缺陷和稳定性估计的后验界等；本轮没有执行或取得这些认证。只严格积分未经认证轨迹的功也不够，功—能路线仍需真实轨迹输入功上界及耗散下界。

四次普通RK4结果、两步长差、能量余额残差、置换残差均可排错，却不能单独证明真实状态误差上界或把浮点末能量认定为真实上包络。能量余额很小也可与状态误差共存；不能用残差直接替换Eerr。

即使尾门通过，要证明全时峰值排序，还需覆盖[0,s]采样间隙的认证输出上界U_A及B某时刻的认证下界L_B，再验证

\[
L_B>\max\{U_A,\sqrt{2\overline E_A(s)1001/1002}\}.
\]

本报告没有这样的早期上下界、状态误差认证或严格排序裁决。非线性交换虽精确保留能量和器件历史，固定u1的峰差是否以及多大，仍属于独立数值观察及后续认证问题。

# R007：总变形回零如何改变力回零候选的端点与取等

**结论：新增δ(T)=δ(0)会排除原单符号取等路径，原精确可行集合不能照搬。** 原L、U作为力回零大类的必要界仍约束这个更小的闭合子类；对其非零可行轨迹，取等条件实际上不成立。本轮不给闭合子类的新精确可行集合，给出严格反对证据及两种明确可行构造。

## 1. 新约束是带符号黏滞流动积分为零

沿用原候选：k,c,α,V,T>0，q=1/α、a=c^(−q)，g(F)=a sgn(F)|F|^q；Fdot=k[v−g(F)]，|v|≤V几乎处处，v=δdot可测有界、F及δ绝对连续，F(0)=F(T)=0。由ODE直接积分：

\[
 \delta(T)-\delta(0)
 =\frac{F(T)-F(0)}k+\int_0^Tg(F(t))dt
 =\int_0^Tg(F(t))dt.
\]

因此新增总变形回零等价于

\[
 \boxed{\int_0^Tg(F(t))dt=0.}
\]

非零力过程必须有正、负力的非零区间；单符号非零过程不可能满足。α=1时化为∫Fdt=0，α≠1时是带符号幂的平衡，不能用普通力面积替代，尤其不能对实际α≈0.3硬套线性式。

## 2. 原取等路径的非零残余

0<M<B=cV^α，τ↑、τ↓、τ=τ↑+τ↓以及L、U_T沿用W5候选定义。最快单正瓣：+V升至M，再−V回到0。它虽然初末力回零，但

\[
 \Delta\delta_+=V[\tau_\uparrow(M)-\tau_\downarrow(M)]>0,
\]

因为同一f>0的升程分母V−g(f)小于降程分母V+g(f)。负瓣的残余反号。若在正峰驻留s，必须v=g(M)，额外残余s g(M)>0；在F=0等待v=0不能消除它。

所以原最小耗散的“零力等待—单正瓣”以及最大耗散的“单正瓣加峰值驻留”均不属于总变形闭合类。只指出这些构造不合法还不足以排除其他取等路径，下面另给必要取等条件分析。

## 3. 原界仍必要，但闭合非零轨迹不能取端点

新增约束取的是原力回零类的子集，因此原必要条件T≥τ(M)、L(M)≤D≤U_T(M)仍必要。它们的正确性状态随R014审核；本文不重证原L/U。

对于闭合类中实际存在的M>0轨迹，可进一步作以下经典取等排除：

- **下端点不能达到。** 取包含绝对峰M的同符号连通力瓣。该瓣两端力为0，其耗散至少是原下界L(M)；这是原必要性论证在该子区间的直接复用。总变形闭合又要求另有反号力的非零区间，其耗散严格正，故整个D>L(M)。
- **上端点不能达到。** 原证明的绝对力包络e(t)=min{M,z↑(t),z↓(T−t)}在0<t<T严格正。这里两条包络均在M处截断，只反演[0,M]上的τ函数，不将q>1的反向解延拓至无限状态。若D=U_T(M)，非负连续差的积分为0迫使|F(t)|=e(t)处处成立；连续F便不能在窗内过零，必须保持同号，与∫g(F)=0矛盾，故D<U_T(M)。

故非零可行闭合轨迹满足严格必要条件

\[
 \boxed{L(M)<D<U_T(M).}
\]

**这不是新的精确可行开区间。** 未证明其中任意D可达，未给闭合类极值或显式间隙；不能把严格不等号换成新的sharp/充要结论。M=0时D=0，不能写严格界。

### 一个直接推翻“原可行集合原样移植”的端点例

当T=τ(M)时，原U_T(M)=L(M)，原候选有一个可行耗散点。新增闭合条件则不可能同时满足D>L与D<U；等价地，最短往返时间的等号条件强制单符号最快升降，无时长再安排反号补偿。

在线性Maxwell取k=c=V=1（单位分别kN/m、kN·s/m、m/s）、M=0.5 kN，

\[
 T=\tau(M)=\log3\ \mathrm{s},\quad
 L=\log3-1\ \mathrm{kN\,m},\quad
 |\Delta\delta|=\log(4/3)\ \mathrm m>0.
\]

所以原可行点在新增端点条件后严格不可达。这是单器件本构/受控输入反对证据，不是建筑地震反例。

## 4. 最简可行正负双瓣（可测控制）

先完成正瓣最快升降，再取其负号镜像：−V走向−M，+V回到0。g为奇函数，两瓣总变形增量严格相消，耗散相加；中间过零时正瓣卸载与负瓣加载都用−V，无衔接矛盾。

只要2τ(M)≤T，可插入零力/零速度等待得到

\[
 F(0)=F(T)=0,\quad\delta(T)=\delta(0),\quad
 \max|F|=M,\quad D=2L(M).
\]

两瓣若各在±M驻留同一s≥0且2τ+2s≤T，仍闭合，D=2L(M)+2aM^(1+q)s。**这些只是充分构造**，不是2τ为必要最小时长，也不是2L为闭合类最小耗散；正负峰幅值不等或其他控制可能更优，本轮不求解。

上述bang开关允许可测有界v，δ仍AC；若新增速度连续、加速度上界或窗外静止衔接，不能把这些开关构造继续当作该更小类的取等解。

## 5. 线性Maxwell的连续控制解析对照

令α=1，ω=2π/T，指定

\[
 F(t)=M\sin(\omega t),\quad
 \delta(t)=F(t)/k+\frac{M}{c\omega}[1-\cos(\omega t)].
\]

则初末F和δ都为0，且

\[
 v(t)=\frac{M\omega}{k}\cos(\omega t)+\frac Mc\sin(\omega t),\quad
 \|v\|_\infty=M\sqrt{(\omega/k)^2+c^{-2}},\quad
 D=\frac{M^2T}{2c}.
\]

因此只要该连续速度幅值≤V就有明确可行解。取同一k=c=V=1、M=0.5，T=2π s，则最大速度1/√2 m/s<1，D=π/4 kN·m。该例在[0,T]控制连续；端点速度为0.5 m/s，若还要求与窗外零速度连续衔接，就要另造路径，不能说本例已满足那个额外条件。

单正瓣的线性残余闭式为

\[
 \Delta\delta_+=-\frac{cV}{k}\log[1-(M/(cV))^2]>0.
\]

[小合成脚本](validate_examples.py)核同一参数点：单瓣残余0.28768207245 m；镜像双瓣总时长2log3、D=2(log3−1)，残余约2.8e−17 m；连续正弦端点残余约1.3e−16 m。解析段积分与独立Simpson校验见 [数值记录](example_validation.json)。这是一个合成参数点的核验，不是普遍证明或大扫参。

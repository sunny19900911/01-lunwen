# R004：阻尼器布局的最小几何—模态筛选接口

**结论：只需Link两端及其连接信息即可建立轴向几何接口，不需要全楼节点时程；但仅坐标、楼层/隔板名和属性，不能算出模态变形。** 模态初筛还须每端少量模态位移，或刚性隔板模态平移/转角。端点绝对位移大、单阶端点差大，都不能据此认定最终最优位置。

## 1. 假设与基本推导

对一只**纯轴向、直接连接实际I/J端、无未计端偏置**的两力Link，参考全局坐标xI、xJ，L=|xJ−xI|>0，物理轴与两点连线一致时

\[
 n=(x_J-x_I)/L,\quad |n|=1.
\]

由变形后长度的一阶展开

\[
 |(x_J+u_J)-(x_I+u_I)|-L
 =n^T(u_J-u_I)+O(|u_J-u_I|^2/L),
\]

得吸收侧功共轭的总轴向伸长

\[
 \delta=n^T(u_J-u_I)=B_ju,\quad
 B_j=[-n^T,\ n^T].
\]

应先核原生局部U1轴和功符号；Angle=0不能自动证明全局X。若轴并非端点连线、L=0或几何精度不足，用明确的装置局部轴/运动学定义，不能除以近零长度猜方向。

在选定线性参考模型模态中，u=Σr φr qr，故

\[
 \delta_j=\sum_r b_{jr}q_r,\qquad
 \boxed{b_{jr}=(\phi_{Jr}-\phi_{Ir})\cdot n_j.}
\]

这里j表示器件、r表示模态。原请求写作b_j时，是固定模态r后的同一系数。若只保留部分模态，上式是受截断误差约束的近似，质量参与率高不单独保证局部b与响应完备。

b仅是几何运动学投影；其量纲随φ与q的约定，不能一律叫无量纲。φr改乘s、qr除以s，b改乘s而物理δ不变；同一模态内比较位置可用共同归一，但跨模态不能直接比较未经统一约定/响应权重的|b|。模态换号也会改变b号而不改变物理响应；近重根的单阶排名还会随基选择改变，应审查相应模态子空间。

## 2. 从隔板少量自由度恢复端点运动

实际刚性隔板仅面内运动时，端点a所属隔板参考点为Oa，ρa=xa−Oa。采用与该参考点一致的平移Ta、绕全局Z小转角θa：

\[
 u_a=T_a+\theta_a e_z\times\rho_a.
\]

Ta保留哪些分量须写明；若确实只取面内运动，Tz=0是模型约束，不是删去已存在竖向运动的理由。令

\[
 \ell_a=n^T(e_z\times\rho_a)=n_y\rho_{ax}-n_x\rho_{ay},
\]

则同刻轴向总相对运动为

\[
 \boxed{\delta=n^T(T_J-T_I)+\ell_J\theta_J-\ell_I\theta_I.}
\]

对每阶模态，把T、θ替换成相应模态值，即得b。转角(rad)乘有符号臂长才是平移长度；不能把离中心的距离直接当轴向扭转臂，也不能混用一个参考点的平移和另一个参考点的坐标。

### 跨层、同层与扭转

| 连接情况 | 可以先判断什么 | 限制 |
|---|---|---|
| 跨层、不同隔板 | 保留两端平移差及两个扭转项；斜撑会将水平相对运动按nX/nY投到轴上。 | 同一跨层连接可因平移/扭转相消而b近零；不可只看层间水平位移差的模。 |
| 同层、同一实际刚性隔板 | 共同平移消去；共同刚体转动也给n·[θ ez×(xJ−xI)]=0，一阶轴向伸长为0。 | 前提是两端实际受同一刚体约束、轴为该端点连线；两端坐标同层不等于同一刚体。 |
| 同层、不同隔板/两塔/独立支撑 | 仍可能有相对平移、相对扭转并激活器件。 | 不能套“同层没有变形”；需要两边各自模态运动或支撑给定位移。 |
| 纯竖直轴、只考虑面内Ta及RZ | nX=nY=0，故此运动子集不激活该轴。 | 有竖向运动、摇摆、偏置或其他DOF时重新计算。 |

同隔板两点可以有非零向量位移差，但它正交于连线，一阶投影仍零。不能用|uJ−uI|代替轴向δ，也不能用|uJ|−|uI|代替它。

## 3. 最小字段与分级数据契约

字段可以按“每Link一行＋少量端点/隔板模态行”提供；不索取全楼节点。

| 层级 | 最小字段 | 通过后能做什么 |
|---|---|---|
| 几何身份 | Link唯一ID；I/J唯一端ID；两端全局XYZ及长度单位；数据来源/行号；安装拓扑类别。 | 查重复/零长/跨层/同层连接，算弦方向及倾角。 |
| 连接与轴 | 两端Story、Diaphragm ID；是否实际刚性约束到该隔板；支撑/固定端标志；有效轴DOF；原生全局轴向量或核实的轴变换；是否存在端偏置。 | 判断能否套直接两端纯轴向公式；未知信息保留unknown，不补0。 |
| 属性身份 | Property ID、器件类型、激活DOF；k、c、α及各单位/来源/verified状态，允许尚未核实。 | 防止把其他Link当Maxwell、把总变形当黏滞元件变形；参数未核也可几何筛选，不能算可靠耗能效果。 |
| 模态路线A | 对每个候选r，只提供I/J实际连接点的全局三向φ；模态ID/频率、同一参考模型身份、归一约定及单位。 | 直接算b，不需要其他节点。 |
| 模态路线B（替代A） | 每个涉及的刚性隔板：O、该r的T/θz、参考点及单位、端点所属约束；固定支撑则提供其已核运动条件。 | 用隔板刚体式恢复端点φ，再算b；不适用于柔性隔板/非刚性内部连接点。 |
| 条件补充 | 实际刚臂偏置r、端部转角模态或运动学映射；串联支撑/连接柔度与局部支路拓扑。 | 当纯端点/隔板映射不成立时，修正实际器件端运动，不把整支路变形算给短Link。 |

本表中的k/c/α不是本轮真实模型已知量。α=0.3时c的单位应为力/(速度)^0.3，不与α=1的c混用。模态位移、几何臂长及单位必须统一后再投影。

## 4. 短Link、刚臂和外部支撑的边界

- **实际端点模态位移若已给足**，且轴/DOF正确，那么即使Link很短，直接轴向投影仍能算该器件的线性化变形；不能笼统说短Link永远需要全楼节点。
- **只有坐标与楼层归属时**，短Link内端可能连在斜撑/连杆/支架内部节点，并不跟随整层刚体运动。此时贴上Story/Diaphragm标签不足以推出φ，须给真实端点模态值或可核的连接约束映射。
- 有刚臂时实际连接点运动一般为u_end=u_joint+θ_joint×r_offset；仅主体节点平移不足。若给出的已经是实际连接点φ，则不再次加偏置，防双计。
- 外部支撑可能变形、转动或受给定支承运动，不能自动设0或套邻层振型。只有约束已核固定时才可取支撑端φ=0。
- 斜撑—器件—连接串联时，整个支路端间伸长包含器件及支撑/连接变形；支路投影不自动等于Maxwell器件端变形。需内部端点或串联协调关系，不能以Link长度当整支路工作长度。
- 大变形、有限转角、方向随动、转动型/多DOF器件、端偏置未计时，须用对应运动学雅可比；本接口的一条固定n不覆盖这些情形。

## 5. 一组合成两层示例（不是归一模态或真实工程）

坐标与位移单位m，转角rad；两层高度差3。中心线斜撑I=(0,0,0)、J=(4,0,3)，L=5，n=(0.8,0,0.6)。隔板参考点分别(0,0,0)、(0,0,3)。另用y=3的同倾角斜撑作扭转偏置对照。

| 场景 | 规定合成运动 | uJ−uI（m） | 一阶δ（m） |
|---|---|---|---:|
| A | 两层共同X平移1 | (0,0,0) | 0 |
| B | 仅上层X平移0.01 | (0.01,0,0) | 0.008 |
| C | 中心线斜撑，仅上层θz=0.001 | (0,0.004,0) | 0 |
| D | I=(0,3,0)、J=(4,3,3)，仅上层θz=0.001 | (−0.003,0.004,0) | −0.0024 |
| E | 同层同刚体I=(0,3,3)、J=(4,3,3)，θz=0.001 | (0,0.004,0) | 0 |

负δ在本例伸长为正的I→J投影约定下表示压缩。C不意味着扭转普遍不能激活斜撑，D就是反例。A表明绝对位移大也可无轴向运动；E表明端点向量差非零也可无一阶轴向伸长。

## 6. 能筛什么、还需什么

本接口能排查几何方向/连接归属错误；识别某个参考模态下的轴向消去或扭转臂差异；比较同一模态、同一归一约定下候选点的|b|；列出跨层、同层异隔板及需要额外映射的部位。b≈0只指该参考模态的小变形轴向激活弱，不等于所有工况下器件无效。

最终布置仍需目标、约束及实际响应：输入方向/频谱与模态坐标历史、不同模态的相位叠加、足量局部模态、器件状态与本构、安装后模型变化、支撑/连接强度、最大器件力/行程与局部截面需求、数量/费用/可施工性等。单阶|b|最大或一个绝对位移最大，不能替代这些比较。

对α=0.3的串联Maxwell，δdot=Σ b_jr qdot_r是几何输入，力还由内部状态和完整叠加历史决定；非线性幂不能逐阶相加。不得把b²直接命名为固定模态附加阻尼、套α=1固定τ=c/k，或从几何分数宣称所有响应改善。单阶端点差、绝对位移或纯几何排名仅作候选初筛，不宣布最终最优。

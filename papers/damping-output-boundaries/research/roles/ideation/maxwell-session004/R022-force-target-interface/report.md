# R022 真实器件力历史到同一参考主体目标位移差

角色1；开始2026-10-18 02:22:46 +08:00，限10分钟。[冻结协议副本](protocol-copy.md)及9项输入SHA见[input-freeze.json](input-freeze.json)。复用旧R013卷积、既有modal-interface、R012有限模态条件、R001/R004 FNA警告、R009归一接口及角色6已核Londoño定位；没有新读论文原件、外搜、真实数组或求解。

## 裁决

给定**同一D模型真实完整端口力历史**后，固定线性参考主体的位移差有精确经典卷积身份。完整质量归一Eigen基、共同经典背景阻尼、同外力及主体初态下，

\[
\boxed{y_D(t)-y_U(t)=
-\sum_{j=1}^{n}\sum_{d=1}^{p}\gamma_j\beta_{dj}
\int_0^tG_j(t-\tau)F_{D,d}(\tau)d\tau.}
\]

它是给定力后的条件重构，**不是非线性模态独立定理、不是将旧力移到新布局的预测**。实际FNA的参考K、残余力及软件P符号尚未由本报告认证，不能直接套真实导出。现有完整32只子集只给部分贡献，不能闭合88只总差。本轮为作者侧经典接口候选，待独审。

## 1. 很短的推导与适用窗

先在同一约束后动力坐标固定M=Mᵀ≻0、K=Kᵀ≻0、背景C及功共轭端口δ=B u。U删除全部指定支路，D保留这些支路，且

\[
M\ddot u_U+C\dot u_U+Ku_U=f,
\qquad M\ddot u_D+C\dot u_D+Ku_D=f-B^TF_D.
\]

这里F_D是与δdot功共轭的恢复力，结构左端为+BᵀF_D；含Maxwell串联弹簧效应，不是将总端口速度代入裸黏壶式所得的力。主体初始位移/速度相同，因此w=u_D−u_U满足Lw=−BᵀF_D及w(0)=wdot(0)=0。器件可有初力，但其作用已包含在真实F_D历史中，不另给结构差状态添加一次初力齐次项。

完整确切Eigen基满足ΦᵀMΦ=I、ΦᵀKΦ=diag(ω_j²)，且同一基中ΦᵀCΦ=diag(2ζ_jω_j)。令γ_j=ℓᵀφ_j、β_dj=B_dφ_j，模态差坐标w_j=φ_jᵀM w，固定输出y=ℓᵀu只取位移/相对位移。投影后

\[
\ddot w_j+2\zeta_j\omega_j\dot w_j+\omega_j^2w_j
=-\sum_d\beta_{dj}F_{D,d}.
\]

对ω_j>0、0≤ζ_j<1，因果单位模态质量位移核为

\[
G_j(t)=\mathbf1_{t\ge0}e^{-\zeta_j\omega_jt}
\frac{\sin(\omega_j\sqrt{1-\zeta_j^2}\,t)}
{\omega_j\sqrt{1-\zeta_j^2}}.
\]

它满足G_j(0)=0、G_j'(0+)=1及t>0的齐次方程，Duhamel积分即给首式。有限维、局部可积真实力及有限观测窗即可使该积分有定义。

ζ=0仍允许有限时精确身份，但无阻尼核不属于L1(0,∞)，不能因此使用无限时域BIBO/Young增益。“稳定”必须区分自由有界与渐近衰减；若需全时L1核界，要另核相应正阻尼等条件。ζ≥1或非经典C也有适用的其他核/矩阵卷积，但不能冒用本标量欠阻尼核；本轮不扩推。

## 2. 质量、尺度及端点符号

若给出的原形状ψ_j只是同一确切共同模态的任意一致缩放，m_j=ψ_jᵀMψ_j>0，原投影记a_j=ℓᵀψ_j、b_dj=B_dψ_j，则

\[
y_D-y_U=-\sum_{j,d}\frac{a_jb_{dj}}{m_j}(G_j*F_{D,d}).
\]

φ_j=ψ_j/√m_j后γβ=ab/m。ψ_j乘非零实数s时a,b同乘s，m乘s²，整个系数不变；共同模态翻号亦不改变贡献。显示归一振型不得与另一缩放的质量列拼接，不能把列名ModalMass当已认证广义质量；不逐节点取绝对值。

纯轴向、无偏置时，固定方向e上的β_dj=eᵀ(φ_Jj−φ_Ij)。真实刚臂、偏置、转角、隔板约束或多点约束均应包含在B中。数学上改约定B_d→−B_d必须同时F_d→−F_d，才保持BᵀF及贡献不变；只反力列或只反β会翻错符号。实际交换I/J可能同时改变局部轴，未必等于单独B变号，须按实际运动学重建。软件P是否为该共轭恢复力、取哪一端/哪一轴、是否需反号或单位换算，都要字段和校准证据，不能凭表名断定。

频率统一用rad/s，Hz乘2π；m、形状、力与长度/转角单位一致。重频簇还要确认导出基已共同对角化实际C，而不是仅刚度对角。Ritz投影内的对角化不自动成为完整确切Eigen身份。

## 3. 缺模态、缺器件和采样力的余项

设完整模态集J、完整器件集D；只计算确切模态子集I和已知真实力子集S。部分量Y_IS=−Σ_(j∈I,d∈S)γ_jβ_dj(G_j*F_d)，精确补项可无重叠地写成

\[
y_D-y_U=Y_{IS}+R_{mode}+R_{device},
\]
\[
R_{mode}=-\sum_{j\notin I,\ d\in D}\gamma_j\beta_{dj}(G_j*F_d),
\quad R_{device}=-\sum_{j\in I,\ d\notin S}\gamma_j\beta_{dj}(G_j*F_d).
\]

两项交集不重复计数。未归一时各系数换成ab/m。即使全部模态齐，32只力仍缺另外56只贡献；力完整不等于模态完整。各项有符号且可相消，部分和不是总差的天然上/下界，也不是“实际移除这32只、保留其余56只”的反事实响应，后者会改变其余器件力。

若对遗漏对的投影、核和真实力范数已有认证来源，有限窗H内可用经典Young界

\[
\|R\|_{\infty,[0,H]}\le
\sum_{(j,d)\in missing}\frac{|a_jb_{dj}|}{m_j}
\|G_j\|_{L^1(0,H)}\|F_{D,d}\|_{\infty,[0,H]}.
\]

缺这些量时保留未核R，不能按装置数量、能量占比、全局质量参与率或旧300阶列表补零。旧R012的逆谱正项尾界不是这里有符号时程余项的自动证书；有限近似Ritz还需额外投影/动力残差，不能仅加上述确切Eigen尾和。

如果只有采样力Fhat，计算的是重构力的贡献，真实差还要加同样核作用于F_D−Fhat的项。时间轴、插值及积分误差必须另核。力记录在输入结束时截止，并不说明此后器件力为零；本身份只覆盖力历史已认证的时间窗，延伸尾段需相应真实力/误差证据。

## 4. 参考变化、非线性耦合及FNA的配对

本身份虽是线性参考的卷积，F_D仍由D的共同状态和所有器件反馈求得，通常耦合模态。把历史当已知函数以后能逐核叠加，不表示实际非线性求解可拆成独立线性模态。把同一F_D移到新B仅定义一个规定外力重放，不能声称那是新布局的被动器件响应。

如果主体初态不同，另有初始位移/速度差的齐次项。若外力、主体M/K/C或其他非线性不同，以参考算子L_U作用于w时还出现

\[
\Delta f-(M_D-M_U)\ddot u_D-(C_D-C_U)\dot u_D-(K_D-K_U)u_D
\]

及未列主体非线性余力等附加项。坐标/约束不一致时还要先认证功共轭变换；这些条件未齐不能只写−BᵀF_D。

复用CSI已核R001/R004定位：FNA可能使用K_eff=K_0+K_N，并写L_eff u_D=f−[r_N,D−K_Nu_D]。若恰有K_N=Bᵀk_eB、r_N,D=BᵀF_D，令R_D=F_D−k_eBu_D，则

\[
L_{eff}u_D=f-B^TR_D.
\]

此时残余力R_D的卷积参考是相同算子的U_eff（L_eff u_Ueff=f），不自动等于去支路物理U_0（L_0u_U0=f）。目标若是u_D−u_U0，可直接用K_0与完整F_D；或在相同M/C下用

\[
L_{eff}(u_D-u_{U0})=-B^T[R_D+k_eBu_{U0}].
\]

因此K_eff与完整F_D直接搭配而漏掉有效刚度修正会重复计入线性弹簧效应。k_e不是Maxwell实际串联κ；某DOF k_e=0也不证明全部K_N=0或真实F_D=0。背景C可能随建基刚度/工况定义变化，“同为5%”不证明C相同。实际FNA算子、当前P是完整力还是余力、当前约束与阻尼路径都未由本报告认证；角色3另核原文也不代替实际设置身份。

## 5. 只交目标和端口即可的最小字段

完整清单见[minimum-fields.json](minimum-fields.json)，核心如下；可以直接给经认证γ/β，不必导出全楼节点。

| 小表/记录 | 最小内容 |
| --- | --- |
| 参考身份 | 同一约束坐标/质量源/刚度状态/M-K-C身份，物理裸K或有效K及配套力定义，完整Eigen及共同经典C证据 |
| 模态 | mode_id、ω(rad/s)、实际背景ζ、m或质量归一证明、同一缩放/共同相位；需覆盖完整集或列明余项 |
| 固定目标 | y=ℓᵀu的坐标/方向/差分权重、每模态有符号γ；两点相对位移给两点或直接投影 |
| 器件端口 | 全部指定device_id/DOF、每模态有符号β，或实际I/J形状与轴/偏置/转角/约束映射；力—变形共轭证据 |
| 真实力 | 同一D工况全部指定器件的F_D(t)、完整共同窗口/时间轴、单位、导出列到共轭力的映射和符号；采样重构/误差 |
| 比较合同 | 外力及主体初态确实相同的证据，工况/输入倍率/初始续算身份、器件初态及力历史来源；遗漏表和完整性状态 |

对这个**差值**，共同f已经抵消，不必另要输入模态参与因子来计算首式，但必须有同输入身份的证据。要恢复绝对y_D还需y_U，或另有输入及初态以求参考响应；只有差值不能给两者各自实际峰。参与率平方量不能替代有符号β/γ，设计阻尼百分比不能替代实际背景C。

当前32只数据只能标partial_32_of_88，不能输出闭合的88只总差。旧0/3不同模型的质量、振型、归一或阻尼系数不迁移。最小字段的“可只给局部投影”也不豁免完整模态和余项证据。

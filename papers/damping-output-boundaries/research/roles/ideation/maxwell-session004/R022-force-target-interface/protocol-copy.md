# 器件力到目标位移：经典条件接口的冻结范围

本任务把已知线性参考系统/模态卷积组织成可审阅的数据接口，不提出新理论，也不假定当前真实FNA已满足条件。先复用现有modal-interface、R001 FNA警告与Londoño原文，避免重复推导已审工具。

固定比较：约束后同一有限维线性主体M/K/C、同一外力及主体初态。U为去掉全部指定Maxwell支路的参考，D保留这些支路；M/K正定、C稳定且在完整确切Eigen模态中经典对角化。D方程为M uD''+C uD'+K uD=f−B'F_D，U右侧为f。F_D是D轨迹中与δ=Bu功共轭、包含串联弹簧效应的完整端口力历史，不是随意移植到另一布局的力，也不等于软件任意标号原列。B、坐标约束与符号须核。

目标仅为固定线性位移或相对位移y=ell'u。完整质量归一Eigen基Φ，C对角2ζjωj，0≤ζj<1；核候选精确身份

`yD-yU = -sum_j sum_d gamma_j * beta_dj * (G_j * F_D,d)`，

其中gamma_j=ell'φj，beta_dj=B_d φj，G_j(t)=exp(-ζjωjt) sin(ωj sqrt(1−ζj²)t)/(ωj sqrt(1−ζj²))，t≥0。未质量归一但仍正交时，核modal mass mj的除数及尺度/符号变换不变性，避免拿显示归一的振型当单位模态质量。

非线性F_D与模态状态仍反馈耦合；给定已有力历史后的卷积身份不能当新布局的闭式预测或独立线性模态替代。若主体非线性、参考K/C不一致、初态不同、模态不完整或FNA算子/输出力定义未核，必须写额外项/缺口，不将身份直接套真实数据。软件若参考K含有效Link刚度，应核与全部端口力或残余非线性力的搭配，避免重复加弹簧力。

最小接口只需目标gamma、有符号端点投影beta（或真实I/J端点振型/几何/约束）、频率/实际背景模态阻尼/质量或归一认证、同一工况完整F时间轴与单位/初态/模型身份。全楼其他节点可不交。截断模态或缺失器件须保留未核余项；现有32完整子集只能给部分贡献，不闭合88只的总有控—无控差。Ritz不自动等于完整确切Eigen基；旧300阶不同模型系数不搬用。加速度/总层剪不能直接照搬位移式。

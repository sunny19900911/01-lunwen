## 1. 只用M-C018的定义和可达类

固定κ,c,α,V,T>0，h>0，σ∈{−1,+1}，F(0)=0、F(T)=σh；F、δ绝对连续，v=δdot可测、|v|≤V几乎处处，**末总δ自由**。记q=1/α、γ=c^(−q)，本构为Fdot=κ[v−g(F)]、g(F)=γsgn(F)|F|^q。在x≥0上记r(x)=γx^q、P(x)=x r(x)=γx^(1+q)，且B=cV^α满足r(B)=V。真实耗散D=∫₀ᵀF g(F)dt，不是总端口功。

仅在0≤x<B定义源函数

\[
\tau_\uparrow(x)=\frac1\kappa\int_0^x\frac{ds}{V-r(s)},\quad
\tau_\downarrow(x)=\frac1\kappa\int_0^x\frac{ds}{V+r(s)},
\]
\[
\Phi_\uparrow(x)=\frac1\kappa\int_0^x\frac{P(s)}{V-r(s)}ds,\quad
\Phi_\downarrow(x)=\frac1\kappa\int_0^x\frac{P(s)}{V+r(s)}ds.
\]

为简写，以下τ(M)=τ_h(M)=τ↑(M)+τ↓(M)−τ↓(h)，L(M)=L_h(M)=Φ↑(M)+Φ↓(M)−Φ↓(h)，U(M)=U_{T,h}(M)=L(M)+P(M)[T−τ(M)]。

源定理已审：指定M存在当且仅当h≤M<B、τ(M)≤T；该峰下D**恰取满**[L(M),U(M)]。允许反号峰/换号过程不扩大该区间，σ仅改变同符号实现的方向。本轮从这项完整正问题反演，不重新假定未审控制类。

## 2. 时间域、导数消项与严格单调性

先判h≥B时不可达，且不调用h处上升积分。若0<h<B，令t_min=τ↑(h)=τ(h)。在[h,B)上

\[
\tau'(M)=\frac1\kappa\left[\frac1{V-r(M)}+\frac1{V+r(M)}\right]
=\frac{2V}{\kappa[V^2-r(M)^2]}>0,
\]
\[
L'(M)=P(M)\tau'(M)>0,\qquad
P'(M)=(1+q)\gamma M^q>0.
\]

r在正数B附近光滑，r′(B)>0，故V−r(M)在B附近线性趋零，τ↑(M)及τ(M)趋于∞。因此T≥t_min时恰有唯一M_T∈[h,B)满足τ(M_T)=T；T=t_min时M_T=h，T>t_min时M_T>h。所有可行峰正好组成J=[h,M_T]。

在J上对U求导，源下界导数与过渡项精确抵消：

\[
U'=L'+P'(T-\tau)-P\tau'=P'(M)[T-\tau(M)]\ge0.
\]

若T>t_min，则M<M_T处U′>0，虽U′(M_T)=0，对任意M₁<M₂≤M_T仍有∫_(M₁)^(M₂)U′>0。因此U在整个闭区间J严格递增，不能因端点导数为零误判逆不唯一。L同样严格递增。h>0确保全部P、P′为正；本轮不扩到h=0的另一端点类。

## 3. 完整D域、受限逆和闭区间公式

先设0<h<B且T>t_min，定义

\[
D_{min}=L(h)=\Phi_\uparrow(h)>0,\quad
D_0=U(h)=D_{min}+P(h)(T-t_{min}),\quad
D_{max}=L(M_T)=U(M_T).
\]

严格有D_min<D₀<D_max。L的受限逆L_J⁻¹仅定义于[D_min,D_max]，值域J；U_J⁻¹仅定义于[D₀,D_max]，值域J。给定实数D，必须先判域：**D∉[D_min,D_max]则峰集合为空，不对非法D调用逆函数。** 域内定义

\[
M_+(D)=L_J^{-1}(D),\qquad
M_-(D)=
\begin{cases}
h,&D\le D_0,\\
U_J^{-1}(D),&D>D_0.
\end{cases}
\]

等价地，域内可写M_−=U_J⁻¹(max{D,D₀})，这里截取的是**U逆的合法参数**，不是把域外D改成可达耗散。完整结论为

\[
\boxed{\mathcal M(D)=\{\max_{[0,T]}|F|:\text{满足全部冻结条件且耗散为D}\}
=[M_-(D),M_+(D)].}
\]

证明必要性：L(M)≤D等价于M≤M_+；D≤U(M)在D≤D₀时对全部J自动满足，在D>D₀时等价于M≥M_−。在M=M_+处U(M)≥L(M)=D，故M_−≤M_+，区间非空。若D_min<D<D_max，下端为h时上端>h；下端>h时它小于M_T，且U(M_−)>L(M_−)，所以同样M_−<M_+。

完整D域也有充分性：任意D∈[D_min,D_max]均有M=L_J⁻¹(D)，且D=L(M)≤U(M)，源定理提供真实轨迹。反之域外，L(M)≥D_min、U(M)≤D_max排除全部峰。因此不是只给一组必要条件或漏掉D域内某个耗散值。

## 4. 区间中每个M都可实现

任取M∈[M_−,M_+]，令Δ=T−τ(M)≥0，并取

\[
\ell=\frac{D-L(M)}{P(M)}\in[0,\Delta].
\]

分母因M≥h>0而严格为正。复用M-C018已审构造：零力等待Δ−ℓ，以v=σV最快升至σM，以v=σr(M)驻留ℓ，再以v=−σV最快降至σh。上/下行时间分别τ↑(M)与τ↓(M)−τ↓(h)，总时长恰T，驻留速度r(M)<V；峰为指定M，耗散L(M)+P(M)ℓ恰为D。积分v定义总δ即可，因末δ自由无需另闭合。所有区间端点及内部峰都是真正可达，不是上下界之间未填满的空隙。

## 5. 端点、最短时间及域错误反例

| 条件 | 固定D的完整结论 |
| --- | --- |
| h≥B | 所有D均为空；有限时间不能从0达到B或越过它。 |
| 0<h<B，T<t_min | 所有D均为空，不定义M_T或上述逆。 |
| T=t_min | 仅D=Φ↑(h)时有集合{h}；其他D为空。单独处理，不借非退化逆。 |
| T>t_min，D<D_min或D>D_max | 空集，包括h>0时D=0/负数。 |
| D=D_min | 仅峰h；等待后最快升至末力即可。 |
| D=D₀ | 下端h，上端L_J⁻¹(D₀)>h；U逆若调用也恰返回h。 |
| D=D_max | 仅峰M_T，Δ=0、L=U，不能再增加驻留。 |
| D_min<D<D_max | 区间非退化，且全部中间M可达。 |

域问题的最小反例：T>t_min且D=D_min合法、峰集合{h}，但D_min<U(h)，所以未经截取的U_J⁻¹(D_min)根本无定义。反过来将D>D_max硬截成D_max再报告{M_T}，则改变了固定D题目。必须保留前置空集判定。

σ同时翻转F与v，不改变τ、D或峰集合。若给的是净端口功W，仅作D=W−h²/(2κ)换元后走同一判域；对应W可达域为[D_min+h²/(2κ),D_max+h²/(2κ)]，退化情形同移。不能混淆真实耗散和端口功。

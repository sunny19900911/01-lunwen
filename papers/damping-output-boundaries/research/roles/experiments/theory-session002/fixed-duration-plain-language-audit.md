# 固定时长：固定一栋楼与所有楼的边界核对

2026-10-17。只读C030原件与独审，解释性核对，无新推导或实验。

**解释**

在已审前提下，固定一栋楼和两个阻尼状态，再限制输入时长，可以得到依赖这栋楼的上限。每栋楼各有上限，不等于所有楼共用一个上限：换了质量、刚度和自然时间尺度，控制常数也可以变化。

C030的压缩构造同时改变模型和输入：质量不变，把楼的刚度提高、固有频率提高，阻尼配套调整以保持原来的模态阻尼比；再把有界设计加速度波形同样压缩，两状态始终承受同一新输入，加速度幅值无需提高。这样可把较长见证放进预定时长，但对应的楼已经变了。

新模型位移随尺度变小，而弹性剪力还乘上新刚度，两者配合可使两个状态各自的绝对弹性剪力峰保持，峰比也保持，全部自由尾段一起计入。这里没有分别归一化两个响应。

**证据边界核对**

- 这不是只把同一栋楼的地震“播快”，也没有用一栋固定楼承载所有不断增大的见证。
- 跨模型失界须保留C030的阻尼适用范围；已有较高预定阻尼条件下的统一有限界没有被否定。
- 固定频率或刚度范围、真实地震带宽及其他输入形状限制下是否仍有同样结论，现有缩放没有解决。它不是实际短震风险或工程可行性证据。

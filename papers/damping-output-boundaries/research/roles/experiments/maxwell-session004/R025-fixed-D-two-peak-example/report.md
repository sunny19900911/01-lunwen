# R025：相同真实耗散，可以对应两个不同峰力

这是已准入C038的无量纲说明例，状态candidate，待角色2小范围静态独核。预先固定 κ=c=V=α=1、F(0)=0、F(4)=h=1/2、真实黏滞耗散D=1/4；仅比较提前指定的峰M=1/2和3/5，不求整个峰区间。末总变形自由，以δ(0)=0选取位移原点。

本构为 F′=v−F，δ′=v，|v|≤1 a.e.，F和δ绝对连续。允许开关速度跳变。按“零力等待w、v=1最快升力、v=M驻留ℓ、v=−1最快降力”排列。若以各段起点为s=0，力依次是0、1−e^(−s)、M、(1+M)e^(−s)−1；不是数值积分。M=h时降力段长度为0。

已审α=1闭式直接给 τ↑=−log(1−M)、τ降=log[(1+M)/(1+h)]、τh=τ↑+τ降，L=τh−2M+h−h²/2。取ℓ=(D−L)/M²、w=4−τh−ℓ，则总时长恰4、峰恰M、末力恰h，且D=L+M²ℓ恰为1/4。

逐项非负的精确理由：对x>1，有log x>2(x−1)/(x+1)，由导数或正项级数可证；对log2用1/x在[1,2]的严格凸梯形上界得log2<3/4。所以2/3<log2<3/4，第一例L>1/24、D−L>1/8、ℓ>1/2、w>5/2，下降时长恰0。第二例10/11<log(8/3)<1；上界由e>1+1+1/2+1/6=8/3得出。因此L>37/440、D−L>3/40、ℓ>5/24、w>73/72；升降log参数都大于1，各段为正。等待非负亦证明ℓ≤4−τh，且τh<4。

两者速度只取0、1、M、−1，均满足同一个V=1；升力单调至M、驻留在M、降力单调至h，故连续力的真实绝对峰就是指定M，不是采样峰。用分段闭式和原R017的积分恒等式，真实耗散精确为1/4，端部净功 W=D+h²/(2κ)=1/4+1/8=3/8。W与D不能混用；其中1/8是非零末力保留的串联弹簧储能。

末δ由∫v=τ↑+Mℓ−τ降得到，亦满足δ(4)=h+∫Fdt，均非零。它们确实不同：固定D的上述表达δ(M)=τ↑−τ降+(D−L)/M有δ′(M)=−(D−L)/M²；在[1/2,3/5]上L严格增且L(3/5)<D，故δ严格降。此处只是解释两个已固定实例，没有扫描参数。若要求末δ相同或回零，就加了本例没有满足/证明的条件，不能沿用这两个构造。

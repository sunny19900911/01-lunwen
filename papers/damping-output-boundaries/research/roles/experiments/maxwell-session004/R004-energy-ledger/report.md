参数来自 R002 的 K2/RH4X 条件积分回归：`alpha = 0.30`、`a = 2.0006042528243313e-06 m/kN`、`b = 1.1798190016520894e-09`，其中 `k = 1/a ≈ 499848.9824 kN/m`。这些数值仍是条件拟合参数，不能改写为导出属性真值。b 的量纲为 m/[s·kN^(1/alpha)]。

使用原生 `P_I` 一次（kN），逐点确认 `P_J` 与其相同；`U1_mm/1000 = U1_m`；时间单位 s。六条记录均保留原始 0.02 s 网格和全部点。RH4X：0–50 s、2501 点；SHW4X：0–59 s、2951 点；SHW7X：0–53.9 s、2696 点。能量统一以 kN·m 表示。

令 `h = sign(F)|F|^(1/alpha)`，`r = d_pred − d_obs`，预测位移从实测初值出发：

```
Δd_pred = a ΔF + b Δt (h_i + h_(i+1))/2
Wtrap = Σ Favg Δd_obs
ΔUs = a(F_end² − F_0²)/2
Dport = Wtrap − ΔUs
Dforce_trap = b Σ Δt (F_i h_i + F_(i+1) h_(i+1))/2
```

`Dport` 是使用拟合 k 扣除条件弹簧储能变化的端口账本量；`Dforce_trap` 是同一条件模型的力端梯形积分量。

## 差额的离散分解

由于 `Favg·aΔF = aΔ(F²)/2`，观测位移端口功可写为

```
Wtrap = ΔUs + b Σ Δt Favg havg − Σ Favg Δr
avg(Fh) − Favg havg = ΔF Δh / 4
```

因此在相同采样点上严格有

```
Dforce_trap − Dport = (b/4) Σ Δt ΔF Δh + Σ Favg Δr
                       离散乘积项             回归残差功
```

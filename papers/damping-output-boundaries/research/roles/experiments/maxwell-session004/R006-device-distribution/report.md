## 固定参数与离散账本

固定R002 alpha=0.30、a=2.0006042528243313e−6 m/kN、b=1.1798190016520894e−9，k=1/a。未拟合或另选参数，真实属性仍未认证。

```
h = sign(F)|F|^(1/alpha)
Wtrap = Σ Favg Δd_obs
ΔUs = a(F_end² − F_0²)/2
Dport = Wtrap − ΔUs
Dforce_trap = b Σ Δt avg(Fh)
Dforce_trap − Dport = (b/4)ΣΔt ΔF Δh + ΣFavg Δr
r = a(F−F0)+b cumulative_trapezoid(h)−(d_obs−d0)
```

每组CSV同时保留Wtrap、条件ΔUs/Dport、模型Dforce_trap及两项离散差额。最大总恒等式残差为2.14412e-15 kN·m；各组单区间恒等式也通过浮点容差检查。此恒等式来自相同固定模型的经典离散储能/乘积关系，不能作为独立物理验证或连续积分误差界。

192组存在负Dport区间增量，全部原样保留；192行摘要给出每组负值数、最小值与区间。未用裁剪或阈值掩盖负值，也不能仅凭条件离散负增量认证真实设备非被动。

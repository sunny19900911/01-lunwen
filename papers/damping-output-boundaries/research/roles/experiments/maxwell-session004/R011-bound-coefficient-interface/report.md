# M-EXP-R011：经典能量界的计算接口可行性审查

结论：现有新 Maxwell 导出足以复用频率、参与量及局部 P/U1 的已有证据，但尚不能认证或计算实际的 `l'K^-1l`、`b'C^-1b`，也不能认证后续的 `b_j'M^-1b_j`。缺少的是目标输出和装置运动在同一动态坐标中的投影、质量与约束处理、真实背景阻尼及完整性说明。仅补频率或一个统一阻尼百分数仍不够。本次只给最小数据契约，没有计算任何实际常数、求解方程、拟合或重新统计已有模态/装置数量。

本报告只读现有报告及冻结元数据清单。精确来源路径、字节数与 SHA256 逐项保存在同目录 `source_manifest.json`。新模型以“辅助元数据完整性审核-R001”及 W5 的 `metadata_inventory.json` 为事实来源；角色1 R010、文献 R008 给出待审数学接口；几何沿用角色1 R004，FNA/背景阻尼口径沿用文献 R004。旧 `verification-session003` 两份模态核查只用于识别缺件类型，不能把旧 0/3 模型的频谱、质量源、工况或阻尼值迁移为新 Maxwell 模型证据。

现有清单确有 `Modal Periods And Frequencies`、`Modal Participation Factors`、`Modal Participating Mass Ratios`、`Modal Direction Factors`、`Modal Load Participation Ratios`。可以复用已经导出的圆频率及带原单位、原归一约定的参与列；它们没有提供目标点有符号振型，也没有认证质量归一化和真实逐阶背景阻尼。`Modal Participation Factors` 中的 UX/UY 和 ModalMass/ModalStiff 不能不核归一约定就直接改名为质量归一后的输入投影 Γ。`Eigenvalue` 列名、Modal 工况名及 NonModHist 结果标签也不能判定实际采用 Eigen 还是 Ritz。

新模型现有导出未提供足以核定 Modal 定义、质量源、当前时程工况引用、目标点振型和最终背景阻尼的设置。Link 属性指定质量不等于已进入实际质量矩阵；Local Axes 中 Angle=0 与 Defined Length 也不构成 I/J 几何和约束映射。原生本构参数表为空的限制继续存在，不能用条件识别参数补成已核真值。

最先补一小份“分析身份与归一说明”：当前模型文件/修订身份、单位、软件版本、目标时程工况实际引用的 Modal Case、质量源、初始/刚度状态、Eigen 或 Ritz 类型、实际保留的模态及其来源。优先导出软件的 Modal 工况定义和当前时程工况定义小表；该版本具体英文表名以其导出清单为准，现有工作簿没有这些表，不能冒称已取得。Ritz 时另需起始荷载、独立 Link 变形荷载及生成/截断设置。这里要核的是同一个主体 M/K/C 和同一输入，不是只匹配名称。

再补一张“每阶一行”的模态/输入/阻尼小表：同一 Modal Case、Mode ID、ω（rad/s）、模态归一方式与模态质量、真实最终背景 ζ、输入方向及有符号投影，并注明来源。已有频率和参与表直接复用，不重复索取。若提供的是原始振型 ψ，须同时提供与它严格同一缩放的模态质量以及参与因子定义，才能一致地换成 `φ'Mφ=1` 的 φ；不能各自缩放输入列与输出列。对基底输入需明确影响向量 r_g、实际方向/转角/倍率及 `b=-M r_g` 的坐标约定；在质量归一后才有 `φ'b=-Γ` 这一对应。一般外力的 b 则需其自己的投影，不能拿地震质量参与因子代替。

真实背景 ζ 必须来自该时程工况、材料复合项和逐阶覆盖后的最终设置。若软件没有单独导出的最终逐阶表，先给该工况阻尼设置小表或清晰设置页，加上材料项/覆盖定义，由模型方给出最终每阶列及计算依据。工程说明中的“背景5%”、Link 的有效 CE、某条拟合阻尼和器件非线性耗能都不能替代它。若背景不是同一基下的经典对角阻尼，单列 ζ 不够，必须提供实际投影阻尼矩阵或选择经认证的直接矩阵路线。

目标输出先只选一个固定楼层点、隔板参考点或一组明确的上下层点。补其模态位移结果小表即可，通常可从 `Joint Displacements` 的 Modal 工况/Mode 步结果按这些点筛出；具体表名和归一方式需按当前版本核实，不声称现有清单已包含该表。保留点唯一 ID、全局有符号平移/必要转角、坐标、Mode ID 和单位。若目标是刚性隔板上的离心点，可改给相关隔板参考点的模态平移/转角及臂长，必须同时确认实际刚性约束；柔性隔板不能这样替代。层间位移用固定上下点之差，漂移比另给层高。随时刻切换控制点的 Story Drifts 包络不是同一个固定 l，不能直接充当所需输出投影。

装置侧也只先补选定 Link 的实际 I/J 端点，不索取全楼节点或节点时程。最小内容是 Link/端点唯一 ID、全局 XYZ、局部 U1 正轴、偏置、Story/Diaphragm 归属及实际约束。再从同一模态结果中只选这些连接点的 φ；若已经是实际器件连接点值，不重复加刚臂偏置。经过核定后，纯轴向、直接连接且无遗漏偏置时可形成 `B_j u=n'(u_J-u_I)`，继而得到 `B_jφ`。短 Link、支撑内部点、刚臂或同层异隔板仍按 R004 的连接契约处理，不能用楼层标签替代真实端点运动。这里令列向量 `b_j=B_j'`，与外部输入向量 b 分开，避免同名混用。

在同一约束后动态空间、完整质量归一 Eigen 基及正频率条件均已核实时，所需模态数据可以压缩为每阶的 `L_r=l'φ_r`、`G_r=φ_r'b`、`H_jr=B_jφ_r`，连同 ω、真实 ζ 和归一证据，不必交付其余节点振型。此时经典对角背景阻尼下，三类系数分别对应 `ΣL_r²/ω_r²`、`ΣG_r²/(2ζ_rω_r)` 和 `ΣH_jr²`。这是未来可计算的接口说明，本轮没有用现有参与表代入任何数值。

只保留部分模态时，上述非负项的部分和一般低估完整系数，不能塞进完整系统的上界公式冒充保守常数。应附各目标 l、输入 b、装置端口的可验证残余上界。S_K 可改用完整静力柔度；S_C 与质量型系数另需各自完整算子或残余证据，不能由静力柔度替代。全局累计参与率不能认证这些局部尾项；局部荷载 Static/Dynamic 指标也不是对应输出误差界。Ritz 向量可以建立约化模型，但不能因有频率列就当成完整物理 Eigen 基；需核投影 M/K/C、归一及尾项。重复/近重复模态应保留相应整个质量正交子空间和一致投影，不能靠单阶符号或排序凑接。零频/刚体方向不能直接除 ω²；若输出不消去刚体方向，位移型有限柔度界可能不存在。负特征值也不满足所需 K 正定前提。模态质量为零不能除以其平方根来伪造质量归一模态。

尤其需要先解决实际全节点 M 可能包含的零质量平移/转角自由度、多点约束和代数变量。当前报告没有认证这些不存在，故不能把原全节点 M 当作正定矩阵直接取逆，也不能删除零行列或用全局参与率补证。应由模型方提供质量源和约束/动态消元说明，给出保持端口功、储能与载荷映射的一致动态坐标；涉及无质量连接、阻尼或内部状态时，消元未必只是简单静力删点。若物理位移写成 `u=Tq`，相关输出、输入与装置端口都必须随同转换，不能只换质量矩阵而沿用旧 b、l、B。只有该动态空间的 M 正定性和映射已核，才讨论 `b_j'M^-1b_j`。单看少数节点质量正值不能认证整个动态空间可逆。

最小质量补件因此是质量源定义、约束/消元映射的说明及其有效动态质量正定证据；选定端点的组装节点质量/转动惯量小表可作核对，但不是完整证明。软件若提供 Joint Masses/组装节点质量类结果，应只选本次端点和相关主自由度，并注明当前质量源；具体表名按版本确认。刚性隔板主坐标的总质量/转动惯量可以减少节点交付量，但只有在映射和实际约束已核时才足够。质心表、Story Mass 或参与率本身不能给出所需局部质量逆系数。

直接矩阵路线可避免索要全楼振型：由模型方交付同一动力坐标中的已认证稀疏 M/K/背景 C 与少量目标右端，或直接提供带坐标、单位、残差和约束证据的所需标量。系数可通过解 `Kz=l`、`Cw=b`、`Mx=b_j` 后作内积得到，无需显式求逆；本轮没有执行这些解算。通用结果表并不自动给出 C 的逆或局部质量逆，不能声称再补一张普通小表就能无条件完成直接路线。K 的刚体零空间、C 的零阻尼方向仍须处理；C 半正定时只有输入落在其值域等条件已证，才考虑相应伪逆，不能跳过零 ζ 模态。FNA 基中的有效 K 与能量式中的主体弹性 K 必须说明拆分，实际 Maxwell 弹簧储能不能被重复计入；有效 CE 也不能当作所需背景 C。

最省补件的顺序是：先用一份设置说明确定新模型的坐标、质量源和模态/背景阻尼身份；再复用现有频率表，只导出选定输出点及选定 Link 端点的模态位移和几何/约束小表；最后由模型方提供完整性/尾项或直接标量证据。若只完成前两步，最多能得到有明确模型和截断限制的投影或部分和，仍不能认证完整工程上界。即使系数最终齐全，绝对上界还需真实输入积分范数与完整初始总储能 E0；从导出时刻为0或少数器件 F0 为0不能推出整个系统 E0=0。本次不索取新的全节点时程，也不把缺件描述升级为求解或实际上界认证。

以上缺件是“当前导出不能核实”，不表示模型中必未定义。所有来源精确路径和散列以 `source_manifest.json` 为准，完成时另核来源不变。该接口说明保持 candidate，是否用于数学候选及后续补件由主控决定；本单项冻结后停止。

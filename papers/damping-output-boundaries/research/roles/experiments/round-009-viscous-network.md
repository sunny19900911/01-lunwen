# 第009轮：单位三层经典阻尼的被动网络单例核查

2026-10-17。E-EXP-009，`numerical-test`。**本指定单例在双精度误差内通过普通被动黏滞网络重构，六个系数均严格为正。** 它包含1↔3非相邻连接和三个接地项，不能写成仅相邻逐层dashpot拓扑。没有映射工程单位、装置选型或已建造状态。

## 固定模型与全部系数

仅使用M=I、m=k=(1,1,1)，

```text
K = [[ 2,-1, 0],       C_unit = 2 sqrt(K) ≈
     [-1, 2,-1],       [[ 2.709107892087086, -0.794333563328718, -0.172535849031337],
     [ 0,-1, 1]]        [-0.794333563328718,  2.536572043055751, -0.966869412360056],
                        [-0.172535849031337, -0.966869412360056,  1.742238479727033]]
```

ζ=1只用来列每单位ζ的系数；一般Cζ=ζC_unit。令 `cij=−C_unit,ij`，`g=C_unit 1`，不作取绝对值、截负数或优化：

| 黏滞支路 | 每单位ζ系数 | 符号 |
|---|---:|---|
| 1↔2 | 0.7943335633287182 | 正 |
| **1↔3（非相邻）** | **0.1725358490313367** | 正 |
| 2↔3 | 0.9668694123600556 | 正 |
| 1↔共同接地/参考端 | 1.7422384797270314 | 正 |
| 2↔共同接地/参考端 | 0.7753690673669766 | 正 |
| 3↔共同接地/参考端 | 0.6028332183356402 | 正 |

重构 `C_network=diag(g)+Σ(i<j)cij(ei−ej)(ei−ej)ᵀ`，最大元素残差1.39e-16；`C_unit²−4K`最大元素残差4.44e-15，对称性残差1.39e-16。独立助手仅以内存小矩阵运算得到同系数/残差，没有依赖本脚本的矩阵解。

## 被动性和阻尼范围

`eig(C_unit)≈(0.8900837358,2.4939592074,3.6038754716)`，均正，且模态基下 `QᵀC_unit Q=diag(2ω)`。所以对任意Δζ>0，`ΔC=Δζ C_unit`为正定；从网络表示也有

`vᵀΔCv=Δζ[Σgi vi²+Σcij(vi−vj)²]≥0`。

六个系数随Δζ同比正向增加，给出该集总模型的一种普通被动黏滞网络实现。接地端是共同参考运动；若解释成均匀基底输入，相对坐标下接地支路速度为各层相对基底速度。此拓扑不是只有相邻层及底层接地的三支路链，未判断实际建筑如何布置这些非局部/接地连接。

该单位模型与E-EXP-002b的非单位m/k模型不同，不能挪用本页六系数实现后者的C。也未计算传递函数零点，不能据此裁决任何新虚轴零点猜想。一般谱平方根/M-matrix结论若要采用，仍须由验证者另作一般证明；本轮只检查这一指定数值单例。
